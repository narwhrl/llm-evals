# 原神·天空岛｜电影级 3D 场景

实现必须写在 `tasks/genshin-celestia/solution/`。不要把实现写到其他路径，也不要修改本任务的 `task.md`、`README.md` 或仓库其余共享输入。

使用 Three.js + TypeScript + WebGL，高度还原《原神》天空岛（Celestia）的标志性外观，制作具有游戏级视觉品质、宏伟神圣且充满神秘感的完整 3D 场景。

核心要求：严格参考《原神》天空岛现有的远景造型，而不是自行设计普通浮空岛或希腊神庙。

## 场景设计

- 中央主岛：一块极其庞大、不规则的悬浮岩体，上方覆盖绿色草地、少量树林和洁白神圣建筑，下方是巨大崎岖的倒悬岩壁与隐约可见的古老建筑。
- 环形结构：中央主岛外围环绕约七至八座大小不一的悬浮岩岛，通过宏伟的白色弧形桥梁、环形道路和古老柱廊相连，形成天空岛极具辨识度的环状轮廓。
- 中央圣殿：主岛中央耸立一座极其高大的白色多层尖塔，拥有精致的尖顶、拱廊、石柱和层叠建筑结构。塔顶必须具有由多个交错金色圆环构成的巨大天体仪式装置。
- 建筑风格：采用《原神》独特的古代天空文明美术语言，以象牙白石材、淡金纹饰、细长尖塔、复杂拱桥与神圣几何结构为主，融合精致的二次元幻想风格，避免普通希腊神庙或科幻城市。
- 自然与遗迹：岛屿间点缀翠绿植被、悬空瀑布、断裂石桥、残缺尖塔和漂浮碎石，展现古老神域的沧桑与神秘。
- 天空环境：万里高空、辽阔蓝天、无边云海、柔和金色阳光、体积光束和空气透视，云层下方隐约可见遥远的提瓦特大陆。
- 极端尺度：中央岩岛与圣殿必须极其宏伟，外围环形建筑绵延数千米，巨大垂直落差和多层远景营造神明居所的至高威严。

## 视觉要求

采用高品质《原神》式卡通幻想渲染，强调清透的色彩、精致的建筑细节、柔和光影、宏大的空间层次与真实的三维体积。

重点还原天空岛的整体剪影：中央巨型岩岛＋外围环形浮岛与桥梁＋高耸白色尖塔＋顶部金色天体仪。

场景默认以电影级三分之四远景展示完整天空岛，确保第一眼就能认出《原神》的 Celestia。

最终目标：不是一座漂亮的普通浮空岛，而是一座真正悬浮在提瓦特世界之上、神圣、古老、壮丽且充满压迫感的天空神域。

直接生成完整、可运行的 3D 场景代码，不需要角色、游戏玩法、UI、任务系统或其他额外功能。
