# 原神·天空岛（Celestia）

用 Three.js + TypeScript + WebGL 程序化构建的电影级 3D 场景。全部几何、纹理与材质在运行时生成，不依赖外部资源、后端服务或凭证，可离线运行。

## 环境要求

- Node.js 20.19+（推荐 22 / 24）
- 支持 WebGL2 的桌面浏览器，建议 1440 × 900 视口

## 命令

| 用途 | 命令 |
| --- | --- |
| 安装依赖 | `npm install` |
| 启动开发服务器 | `npm run dev` → http://127.0.0.1:5173/ |
| 生产构建 | `npm run build`（先执行 `tsc --noEmit`，再由 Vite 输出到 `dist/`） |
| 预览生产构建 | `npm run preview` → http://127.0.0.1:4173/ |
| 静态类型检查 | `npm run typecheck`（`tsc --noEmit`，`strict`） |

`dist/` 使用相对资源路径，可直接由任意静态文件服务器托管。

## 场景

默认第一帧即为完整的三分之四远景：中央巨型不规则悬浮岩岛与倒悬岩壁、其上覆盖草地树林与白色建筑、极高的多层白色尖塔、塔顶由交错金色圆环组成的天体仪，外围约八座浮岛由白色弧形拱桥、环道与断续柱廊连成环状轮廓，另有悬空瀑布、断裂石桥、残缺尖塔与漂浮碎石。下方是无边云海、柔和金色阳光、体积光束、空气透视与隐约可见的提瓦特大陆。

页面没有角色、玩法、任务系统或 UI。首帧渲染完成后会在 `<html>` 上设置 `data-celestia-ready="true"`，可用于等待初始化完成。

鼠标左键拖拽旋转视角、滚轮缩放；相机以极慢速度自动环绕以展示三维体积。天体仪、云海、瀑布、漂浮碎石与体积光束持续动画。

## 源码结构

| 文件 | 职责 |
| --- | --- |
| `src/main.ts` | 渲染器、相机、灯光、Bloom 后处理、渲染循环、交互 |
| `src/world.ts` | 场景组装：中央岛、圣殿、环形浮岛、桥、柱廊、遗迹 |
| `src/rock.ts` | 不规则浮空岩体与草皮顶面 |
| `src/architecture.ts` | 层叠尖塔、柱廊、尖拱窗、金色天体仪、拱桥、亭阁、残塔 |
| `src/nature.ts` | 树林、草丛、悬空瀑布、漂浮碎石 |
| `src/sky.ts` | 渐变天穹、太阳、云海、体积光束、远处大陆 |
| `src/textures.ts` | 程序化 canvas 纹理 |
| `src/materials.ts` | 集中维护的材质与调色板 |
| `src/random.ts` | 确定性伪随机与噪声 |
