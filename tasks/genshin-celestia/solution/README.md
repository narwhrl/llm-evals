# Celestia · Sky Realm

Procedural Three.js + TypeScript scene inspired by the distant silhouette of Genshin Impact's Celestia: a giant inverted central island, an eight-island ring, ivory bridges and sanctum, and a gold armillary above the spire. All geometry and materials are generated locally; no credentials or external assets are needed.

## Install

```bash
npm install
```

## Development

```bash
npm run dev
```

Open the printed local URL. Drag to orbit the camera and use the wheel to change distance.

## Production build and preview

```bash
npm run build
npm run preview
```
