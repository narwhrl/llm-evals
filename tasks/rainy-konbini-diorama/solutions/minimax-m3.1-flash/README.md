# 雨夜便利店街角 · Rainy Konbini Corner

一个可自由拖拽、旋转、缩放观看的雨夜便利店街角微缩模型。三渲二卡通渲染，无任何 UI 界面元素，全部场景元素都搭建在一个完整的正方形底座上。

## 运行

```bash
npm install
npm run dev        # 开发服务器，默认 http://127.0.0.1:5174
npm run typecheck  # tsc --noEmit
npm run build      # 类型检查 + 生产构建，产物在 dist/
npm run preview    # 预览生产构建
```

不依赖任何外部服务、账号或凭据，资源全部在运行时生成。

## 场景结构

底座是一块 14×14 的方形基座（`src/scene/street.ts` 中的 `LAYOUT`），L 形的马路沿着南边和东边包住街区，便利店正好占住这个街角。

- **便利店**（`src/scene/konbini.ts`）：米白墙板、两扇大玻璃窗、中间一扇自动滑门、条纹雨棚、绿白相间的发光招牌带、墙角凸出的灯箱。店内是按真实便利店布置的一间房：饮料冷柜、冷藏便当柜、货架、饭团架、关东煮锅台、收银台、咖啡机、杂志架、海报、灯箱、储物柜、后场门、地面导视，天花板上有四组暖光灯箱。
- **街道**（`src/scene/street.ts`）：人行道与路缘、斑马线、中心线、停止线、排水沟与箅子、停车位、自行车停放架、路灯、交通信号灯、电线杆与架空电线、路牌、街角护栏、公告栏、空调外机、小巷入口、卡位上的两台自动贩卖机与后侧的两台空调外机、邻楼、灌木与矮墙。
- **道具**：三辆自行车、伞架、垃圾桶、地垫、海报栏、长椅、带灯箱的候车亭、自动贩卖机、路灯。

## 渲染方式

- **三渲二**：所有几何体由盒子拼成（`src/scene/voxel.ts`），使用 `MeshToonMaterial` 配合四段渐变贴图得到动漫式的分层明暗。每个几何体同时生成一份微微外扩的「墨线」副本，用背面渲染的黑色材质画在轮廓上。
- **调色**：`src/scene/palette.ts` 把颜色按 sRGB 书写，写入顶点色时再解码到线性空间，所以调色板里的数值就是眼睛看到的明度。
- **湿地反射**：`src/scene/World.tsx` 用 `Reflector` 在地面放了一面真实镜子，沥青以半透明薄膜的形式覆盖在镜子上，于是招牌、店光和路灯都会倒映在潮湿的路面上。
- **雨**：`src/scene/rain.ts` 里的雨丝完全在 GPU 上计算，CPU 只推进一个时钟；屋檐滴水是独立的粒子系统；地面积水是一块带同心波纹的着色器圆盘。
- **玻璃**：橱窗用自定义着色器，竖直的水痕以不同速度向下流动，柱间散布着静态水珠。

## 动效

持续降雨、屋檐滴水、地面波纹、玻璃上的水流、招牌灯箱的轻微闪烁与呼吸、自动门偶尔开合、远处交通信号灯的定时变化。

## 交互

鼠标左键拖拽旋转，滚轮缩放，右键平移。相机距离限制在 5 到 46 之间，极角限制在地平面以上，模型始终留在画面中央。
