# 柳河铁路小镇 · Three.js 桌面微缩沙盘

一块带木质底座和画框的微缩铁路沙盘：闭合环线绕着小镇运行，经过车站、两座跨河铁路桥（钢桁架桥与板梁桥）和一个平交道口；河上另有一座石拱公路桥。车站、广场、主街、市政厅、教堂、工厂、农场和树林由道路网连成一体。全部模型和贴图在浏览器里程序化生成，没有外部素材，也不依赖后端。

## 安装与启动

需要 Node.js 20.19+ 或 22.12+（Vite 8 的要求）。

```bash
npm install
npm run dev        # 开发服务器，按终端提示打开地址
npm run build      # 生产构建，输出到 dist/
npm run preview    # 本地预览生产构建
npm test           # 轨道与列车运动的单元测试（node --test）
```

部署到子路径时，把 Vite 参数传给构建脚本：

```bash
npm run build -- --base=/railway-town-diorama/claude-opus-5.5/ --outDir=<目录> --emptyOutDir
```

## 使用

打开页面即进入默认状态：傍晚暖色阳光，列车在运行，镜头为近似等距视角，能看到整块沙盘。

| 操作 | 方式 |
| --- | --- |
| 暂停／运行 | 面板「暂停」按钮或空格键。列车、停站计时、道口栏杆和蒸汽一起暂停 |
| 速度 | 面板滑块，0.25×–2.5× |
| 复位 | 面板「复位」按钮或 R 键：恢复初始机位、列车位置、1.00× 速度，列车继续运行；不改变傍晚／夜晚设置 |
| 傍晚／夜晚 | 面板切换或 N 键。夜晚时车站雨棚灯、路灯、部分窗户、钟面和列车灯光会亮起 |
| 视角 | 左键拖动旋转，滚轮缩放，右键平移（范围有限制，不会离开沙盘） |

列车每次到达柳河站都会减速停靠 2 秒再出发；面板右上角会显示停靠剩余时间。

## 结构

- `src/motion.js`：由直线段和圆弧段组成的闭合轨道，按弧长取点；列车运动学（巡航、制动曲线、停站计时、复位）；车厢位姿计算。不依赖 three.js，`node --test` 可直接测试。
- `src/layout.js`：沙盘规划，包括轨道、河道、地形高度、道路、地标位置，以及用占用网格沿街排布建筑和树木（避开铁轨、河道、道路），使用固定随机种子。
- `src/kit.js`：共享材质，以及把静态零件按材质合并成少量网格的几何收集器。
- `src/buildings.js`、`src/landmarks.js`：街道建筑、车站与站台、市政厅、教堂、工厂、水塔、谷仓、船屋、路灯。
- `src/track.js`：沿轨道扫掠的道砟和钢轨、实例化枕木、桥梁、道口和栏杆动画。
- `src/train.js`：水柜式蒸汽机车和两节客车。每节车由前后两个转向架点分别落在轨道上，车体位于两点连线中点，朝向沿该连线，所以每节车在弯道上的朝向各自独立，车间距保持稳定。
- `src/board.js`、`src/trees.js`、`src/lighting.js`：底座、地形、水面、桌面、天空；实例化树木和灯光光斑；傍晚与夜晚之间的灯光过渡。
