# 桌面铁路小镇沙盘

用 Three.js 构建的可运行桌面微缩铁路小镇：有厚度与边框的木质展示底座、
闭合环形铁路、车站、建筑群、河流与铁路桥 / 公路桥、道路、路灯和树木，
一列三节编组（车头 + 两节车厢）的火车持续沿轨道运行。

## 安装与启动

```sh
cd tasks/railway-town-diorama/solution
npm install
npm run dev      # 开发服务，默认 http://localhost:5193
npm run build    # 生产构建，产物在 dist/
npm run preview  # 预览生产构建，http://localhost:4173
```

无需后端、无需凭证。打开页面即看到完整沙盘与运行中的列车。

## 操作方式

| 控件 | 说明 |
| ---- | ---- |
| ⏸ 暂停 / ▶ 运行 | 暂停时列车与到站计时同时冻结 |
| 速度滑杆（0.25×–2.5×） | 实时调节列车速度 |
| ⟲ 复位 | 恢复初始机位、列车位置与 1.0× 速度（昼夜模式保持不变） |
| 🌙 夜晚 / ☀️ 白天 | 夜晚车站、路灯与部分窗户发光，场景保持可见 |
| 鼠标拖拽 / 滚轮 / 右键 | 旋转 / 缩放 / 平移 |

列车每次到达车站自动停靠约 2 秒（状态栏显示「到站停靠…」）后再出发。

## 场景结构

- 展示底座：厚木块 + 深色边框 + 桌面，近似等距视角开场即见全貌。
- 闭合轨道：圆角矩形环线，道砟、轨枕、双钢轨；东西两侧各一座带石墩的
  铁路桥跨越河流。
- 小镇：车站（含站台、雨棚、站牌、长椅）、3 间临街商铺、教堂、镇公所、
  5 栋住宅；主街、车站支路（含平交道）、北岸路（含公路桥）连接车站与
  主要建筑区；8 盏路灯、约 30 棵树。
- 列车：车头与两节车厢各自按弧长定位在轨道上（弯道保持间距与朝向，
  非刚体整体旋转），车轮滚动，车头冒烟。

技术：Vite + Three.js（npm），单文件场景 `src/main.js`，无外部资源。
