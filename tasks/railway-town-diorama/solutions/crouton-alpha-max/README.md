# 铁路小镇沙盘

用 Three.js 制作的桌面微缩铁路小镇：木质展示底座、闭合轨道、跨河石桥、车站、民居与街景，列车常态运行。

## 安装与启动

```bash
npm install
npm run dev
```

浏览器打开 Vite 输出地址即可看到完整沙盘与运行的列车。

## 构建

```bash
npm run build
```

可传入 Vite 的 `--base` 与 `--outDir`，例如部署到子路径 `/railway-town-diorama/crouton-alpha-max/` 时：

```bash
npm run build -- --base /railway-town-diorama/crouton-alpha-max/ --outDir dist
```

## 操作

- 拖动旋转视角，滚轮缩放。
- 「暂停 / 继续」：暂停时车厢与到站停留计时同时停止。
- 速度滑杆：调节列车速度。
- 「夜晚 / 白天」：切换黄昏与夜晚，车站、路灯与窗户发光。
- 「复位」：恢复默认机位、列车位置与速度。

## 内容

- 底座：原木纹理展示台（厚边框），草地、河流、跨河石桥、车站与可辨认的住宅群。
- 轨道：圆角矩形闭合环，桥上段抬高呼应石桥。
- 列车：1 节车头 + 2 节车厢，各按轨道弧长独立采样，转弯时朝向与间距自然。
- 光照：默认暖色黄昏阳光与阴影，夜晚切换式灯光。
