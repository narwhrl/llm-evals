# 暮色铁路小镇

这是一个使用 Three.js 和 Vite 构建的桌面微缩铁路小镇。页面打开后会看到带厚木边框的草地沙盘、闭合铁路、跨河桥、车站、建筑、树木和路灯；一节车头与两节车厢沿轨道分别运行，并在车站停留约两秒。

## 安装与启动

```bash
npm install
npm run dev
```

打开终端输出的本地地址即可。生产构建使用：

```bash
npm run build
```

## 操作

- **暂停列车**：暂停或继续列车与车站停留计时。
- **列车速度**：调节运行速度。
- **切换夜晚**：切换暖色傍晚与夜景照明，夜晚会点亮车站、路灯和窗户。
- **复位**：恢复初始机位、列车位置、白天状态和 1.0× 速度。
- 拖动画布旋转视角，滚轮缩放；列车始终沿闭合轨道运行。
