# CS PVP Diorama — 实现说明

CS 经典拆除模式地图的微缩三维沙盘：雨夜废弃货运站 + 后街街区，三渲二硬朗写实风格，
第三人称全景视角，支持拖拽 / 旋转 / 缩放，无任何 UI 与人物。

## 运行

```bash
npm install        # 安装依赖（three 0.185.1, vite 8.2.2，已锁定）
npm run dev        # 开发服务器（默认 http://localhost:5173）
npm run build      # 生产构建 → dist/
npm run preview    # 预览生产构建（默认 http://localhost:4173）
```

打开页面即为完整沙盘：左键拖拽旋转、右键平移（限制在底座范围内）、滚轮缩放。

## 技术要点

- **渲染**：Three.js `MeshToonMaterial`（4 阶灰度 gradientMap）+ 反向壳法线偏移轮廓线；
  所有静态几何按材质合并（约 300 网格 → 全场景 < 350 draw call）。
- **积水倒影**：单张平面反射 RT（官方 Reflector 算法）+ canvas 积水遮罩 +
  双层涟漪纹理扰动；非积水区叠加低透明度镜面形成湿地面光泽；下沉中路自动剔除。
- **雨夜氛围**：GPU 实例化雨丝（顶点着色器驱动，建筑体内剔除）、屋檐/卷帘门滴水、
  通风口水汽、墙面雨水滑落纹理、随机雷暴闪光（天空 dome + 灯光强度脉冲）。
- **战术光源**：暖黄路灯（闪烁+雨晕）、冷白仓库应急灯、A 点后门红光、
  B 点门卫室暖光（破损日光灯摇摆+频闪）、CT 探照灯（扫掠+体积光锥）、警车红蓝交替。
- **地图结构**：T 出生点（卡车/集装箱/铁丝网/斜坡+破洞口）、A 点仓库（半开卷帘门/
  货架/叉车/承重柱/阁楼铁梯）、中路（双开铁门半开缝隙/高位射击孔/岗亭/排水沟/下水道口）、
  B 点铁皮屋（门卫室内景/消防梯/二楼阳台）、CT 出生点（拒马/盾牌/警车/探照灯高台），
  左侧小巷绕后、右侧高台侧翼、中路主对枪三条路线。

## 自适应画质

检测到软件光栅化（SwiftShader/llvmpipe 等无 GPU 环境）时自动降低阴影/反射分辨率、
雨丝数量并限制帧率，保证可检视；硬件 WebGL 环境全画质运行。

调试句柄：`window.__diorama`（scene/renderer/camera/controls/fx）。
