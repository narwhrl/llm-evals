# CS PVP Diorama

Rain-night freight-yard defusal miniature. Full-viewport canvas, no UI. Drag to orbit, scroll to zoom.

## Run

```bash
cd tasks/cs-pvp-diorama/solution
npm install
npm run dev
```

Open `http://127.0.0.1:5174/`. The scene is ready on the first frame.

## Production

```bash
npm run build
npm run preview
```

Preview: `http://127.0.0.1:4174/`.
