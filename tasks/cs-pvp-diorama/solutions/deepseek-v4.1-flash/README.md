# CS PVP 微缩沙盘（cs-pvp-diorama 候选实现）

一张以 CS 经典拆除炸弹（Defusal）模式巷战地图为原型的**微缩三维实体沙盘**：雨夜的废弃货运站与后街街区，三渲二（cel shading）硬朗卡通质感，第三人称全景视角，可自由拖拽、旋转、缩放观看；画面中**没有任何界面元素与人物**，只有一块正方形混凝土底座上的模型。

- 技术栈：Vite + three.js（r186），依赖仅 `three` 与 `vite`
- **零外部资源**：全部贴图（混凝土、沥青、锈铁、瓦楞铁、木箱、涂鸦、货运编号、弹孔、积水遮罩、雨痕、蒸汽…）在运行时用 Canvas2D 程序化生成，固定随机种子，构建结果可复现；因此没有加载等待，也不需要 loading 界面
- 渲染管线：`MeshToonMaterial` 4 阶色阶 + 自研「法线/深度 Sobel」描边后处理 + UnrealBloom 灯光光晕 + 平面反射积水

## 运行与构建

```bash
npm ci             # 或 npm install
npm run dev        # 开发预览 http://127.0.0.1:5173/
npm run build      # 生产构建（输出 dist/）
npm run preview    # 预览生产构建
```

生产构建可直接接受部署参数（与仓库的候选画廊构建方式一致）：

```bash
npm run build -- --base=/cs-pvp-diorama/<model-id>/ --outDir=<目标目录> --emptyOutDir
```

## 操作方式

整幅画面没有任何 UI，交互直接发生在画布上：

| 操作 | 效果 |
| --- | --- |
| 左键拖拽 | 环绕旋转 |
| 滚轮 / 触控板双指 | 缩放（10 ~ 155 单位） |
| 右键拖拽 / 中键拖拽 | 平移（目标点被限制在底座范围内） |

俯仰角被限制在底座上方，不会穿到底座之下；缩放范围覆盖「整盘全景」到「贴地观察湿地反射」。

## 动态效果

细密雨丝（单 draw call，GPU 驱动）、屋檐/集装箱/卷帘门边缘持续滴水、雨水沿墙面与铁皮下淌、积水实时倒映灯光与雨丝并泛起雨点涟漪、路灯光晕轻微闪烁、探照灯缓慢扫动、警灯红蓝交替、通风口白色水汽、卷帘门细微震动、远处天际偶发雷光电光。

## 代码结构

```
src/
├── main.js                入口：舞台/世界/后处理装配与渲染循环
├── core/                  渲染器、分层约定、相机控制、后处理管线（法线深度 pass、描边+夜空合成 pass）、平面反射、灯光动画、调试审计接口
├── gfx/                   程序化贴图库、三渲二材质工厂（含雨水下淌注入）、材质库、随机与噪声工具
├── build/                 静态几何合并构建器、道具注册表（64 种）与实例化批处理、贴花
├── ground/                湿沥青地面 shader（积水遮罩 + 平面反射 + 雨涟漪 + 湿面高光）与静止水面
├── scene/                 坐标蓝图 layout.js 与各区域模块（T 出生点 / A 区 / 中路 / B 区 / CT 出生点 / 路线街面 / 空中电线 / 岗亭与街区建筑）
└── fx/                    雨丝、滴水、水汽、雷光
```

### 渲染管线

1. `NormalDepthPass`：用覆盖材质把视图空间法线与深度渲染到半分辨率 RT，供描边取样
2. `RenderPass`：正常渲染场景（MSAA ×2 的 HalfFloat 目标）
3. `UnrealBloomPass`：只提取自发光灯具的高亮部分（同样半分辨率）
4. 合成 pass：深度 + 法线 Sobel 描边、程序化夜空渐变、远处雷光、暗角
5. `OutputPass`：输出到画布

主循环每帧做两次场景渲染（法线深度、颜色），平面反射隔帧再叠加一次；所有粒子运动都在顶点着色器里用时间 uniform 计算，逐帧不产生新对象。

## 调试接口

窗口上没有 UI，但 `window.__diorama` 暴露了只读审计与不产生界面元素的控制方法，便于复核：

```js
window.__diorama.audit()          // draw call / 三角面 / 实例数 / 灯光数 / 静态包围盒 / 越界清单 / FPS
window.__diorama.setView('aSite') // 切换预设机位（共 14 个：overview / tSpawn / aSite / aSiteBay /
                                  //   mid / midDoor / bSite / bSiteYard / ctSpawn / elevated /
                                  //   lowAngle / routeLeft / routeRight / sewer）
window.__diorama.setCamera({ position: [x, y, z], target: [x, y, z], fov })  // 任意机位
window.__diorama.setPaused(true)  // 冻结动画时间，便于截图对比
window.__diorama.step(30)         // 以固定步长推进帧并立即返回审计结果（不依赖标签页是否可见）
window.__diorama.setOption('outlineStrength', 1.2)
```
