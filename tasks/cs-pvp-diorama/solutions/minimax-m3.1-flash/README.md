# CS 巷战微缩沙盘 · CS Defusal Diorama

一个可自由拖拽、旋转、缩放观看的《反恐精英》拆除模式地图微缩模型。三渲二卡通渲染，无任何 UI 界面元素，所有建筑、掩体、地形与道具都搭建在一块完整的正方形混凝土底座上。

## 运行

```bash
npm install
npm run dev        # 开发服务器，默认 http://127.0.0.1:5173
npm run typecheck  # tsc --noEmit
npm run build      # 类型检查 + 生产构建，产物在 dist/
npm run preview    # 预览生产构建
```

不依赖任何外部服务、账号或凭据，全部几何体在运行时由盒子拼出，没有任何外部资源文件。

## 地图结构

底座是一块 14 × 14 的方形混凝土基座（`src/scene/layout.ts` 中的 `MAP`），四个核心区域按经典 CS 拆除模式排布：**T 出生点在北侧**，**CT 出生点在南侧**，**A 包点在西北**，**B 包点在东北**，三者由**中路主对枪通道**、**左侧小巷绕后路线**、**右侧高台侧翼路线**三条进攻路径串联。

- **T 出生点**（`src/scene/corridors.ts`）：架高 0.9 的卸货区，三面带刺铁丝网围合；左侧一辆旧厢式货运卡车与斜靠的木梯，右侧三层堆叠的海运集装箱形成高低两个架枪位；正前方是通往中路的缓坡，坡边四连装油桶与木托盘，坡墙有一处破损洞口。
- **A 包点**（`src/scene/sites.ts`）：大型废弃仓库。正面是半开放装卸门廊，卷帘门卷起一半搁在横梁上，危险条纹在梁上；西墙与北墙带壁柱，内侧压深色墙裙；屋顶只覆盖后半段，前半段是敞开的天窗式装卸区，因此炸弹区从上方完全可读。仓内有五层重型货架、中央承重柱、叉车、货台、木箱与麻袋、木板封窗、内开式侧门、通往阁楼的铁梯与阁楼小窗，深度后场门缝透出红光。地面用白色喷漆标出炸弹安放区。外墙边有空调外机、分拣台、工业垃圾桶、涂鸦与弹孔。
- **中路**（`src/scene/corridors.ts`）：两侧混凝土高墙各开一处高位射击孔，中段一道双开式厚重铁门半开形成对枪缝隙；CT 侧有矮墙掩体、木箱与废弃路牌；地面是长方形排水沟，表面覆盖生锈铁格栅。下方连通一条低矮下水道通道，从 T 侧斜坡下进入，CT 侧翼出口。
- **B 包点**（`src/scene/sites.ts`）：露天加半室内混合包点。两层铁皮屋门前的空地上用白漆标出炸弹区，周围是货运托盘、工业垃圾桶、废弃自行车与翻倒的铁艺桌椅。一层是废弃门卫室，有玻璃窗、前后双门、办公桌、翻倒的办公椅、墙上的旧值班表、悬挂的破损日光灯与铁皮储物柜；外侧消防梯直通二楼阳台，可俯瞰 B 包点与侧巷入口。转角立着老式路灯，暖黄灯光在雨中形成光晕。
- **CT 出生点**（`src/scene/corridors.ts`）：警用封锁区。拒马路障与警用盾牌摆出防御阵型，警灯带闪烁的警用面包车停在左侧，右侧是混凝土高台，室外楼梯登上平台，平台上有探照灯、工作灯、发电机、装备箱与沙袋。背后是封闭围墙，印着警徽标识与警戒标语，墙边有备用防弹衣与头盔的模型箱与警示灯。地面划出停车位线与警示胶带。

## 渲染方式

- **三渲二**：所有几何体由盒子拼成（`src/scene/voxel.ts`），使用 `MeshToonMaterial` 配合四段渐变贴图得到动漫式分层明暗。每个几何体同时生成一份微微外扩的「墨线」副本，用背面渲染的近黑材质画在轮廓上。
- **调色**：`src/scene/palette.ts` 按 sRGB 书写颜色，写入顶点色时再解码到线性空间，所以调色板里的数值就是眼睛看到的明度。
- **湿地反射**：`src/scene/World.tsx` 用 `Reflector` 在地面放了一面真实镜子，沥青以半透明薄膜覆盖其上，于是灯光、建筑轮廓与雨丝都会倒映在潮湿的地面上。
- **光**：`src/scene/materials.ts` 的 `poolMaterial` 在地面投出被底座边界裁切的灯光池；钠灯用自发光贴片 + 地面光池表现，避免灯头过曝。

## 动效

持续下落的细密雨丝，屋檐与集装箱边缘滴水，地面积水泛起层层涟漪，钠灯与探照灯随雨势轻微闪烁晃动，远处警灯缓慢明暗交替，卷帘门偶尔细微震动，建筑通风口排出淡淡白色水汽，远处天际偶尔闪过微弱的雷光电光。

## 交互

鼠标左键拖拽旋转，滚轮缩放，右键平移。相机距离限制在 6 到 52 之间，极角限制在地平面以上，模型始终留在画面中央。场景中没有任何 UI 元素，也没有任何人物。
