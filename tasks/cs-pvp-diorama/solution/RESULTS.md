## 已知限制、失败与人工介入

- Vite 对大于 500 kB 的单入口 JavaScript 给出警告；主体来自 Three.js，最终 gzip 体积为 165.83 kB。作品只有一个场景入口，因此未增加无收益的路由级拆包。
- Headless Chromium 软件 WebGL 环境中，Puppeteer 原生 `mouse.wheel` 调用曾超时；同一画布的可取消 `WheelEvent` 被 OrbitControls 正确消费，缩放后的画面已实际检查。原生指针拖拽与键盘路径均由浏览器自动化实际完成。
- 尝试运行 LSP JavaScript 诊断时，环境未提供语言服务器；以生产构建、Node 测试和浏览器控制台/运行时检查替代。
- 需要 WebGL2 浏览器；不提供 Canvas 2D 静态降级图，因为那会伪造任务核心的可交互三维行为。
- 无需人工介入；没有更改共享任务、固定测试、评测配置或仓库根 `main`。
