# CS PVP Diorama — 雨夜货栈微缩沙盘

Three.js + Vite 实现的《反恐精英》经典拆除炸弹（Defusal）地图微缩三维沙盘：暴雨夜的废弃货运站与后街街区，三渲二硬边着色加屏幕空间描边，潮湿沥青实时倒影，全程无人物、无 UI。

## 运行

```bash
npm install
npm run dev      # 本地开发（默认 http://localhost:5173）
npm run build    # 生产构建，输出 dist/
npm run preview  # 预览生产构建
```

纯前端、无后端、无外部资源、无密钥；所有贴图由 canvas 在运行时程序化生成。

## 交互

只有画布本身，页面上没有任何 DOM 控件或文字：

- 左键拖拽：环绕旋转
- 滚轮：缩放
- 右键拖拽：平移

默认机位按底座四角求解，打开即看到完整正方形沙盘（1440×900 下留约 6% 边距）。

## 地图结构

底座为 60×60 的整块灰色混凝土台座（含倒角裙边与四只垫块），所有内容严格落在 ±30 范围内。

- **T 出生点（北侧）**：带刺铁丝网与旧集装箱围出的封闭院子；左侧厢式货运卡车旁斜靠木梯；右侧三层堆叠海运集装箱加高架走道，箱缝可单人穿行；正前方缓坡通向下层洞口与中路，坡墙留有蹲伏观察用的破口。
- **A 包点（西北）**：半开放仓库，正面卷帘门卷起一半，侧面两处木板窗与一扇内开门；室内白喷 A 区标识、五层货架×3、手动叉车、木箱与麻袋、中央承重柱、右上铁皮阁楼（垂直铁梯抵达、带俯瞰小窗）、后场半掩门缝透红光；外墙有空调外机、货运编号牌、带盖垃圾桶，旁边是通往左侧小巷的窄通道。
- **中路（中轴）**：双开厚重铁门半开成对枪缝隙；两侧混凝土高墙带高位射击孔，东侧高台走道可抵达；地面长方形排水沟覆锈铁格栅、沟内积水；CT 侧矮墙掩体后堆木箱与歪斜路牌；地下下水道入口在 T 侧斜坡下、出口在 CT 出生点侧翼；两侧岗亭内可见废弃控制台、座椅与面板冷光。
- **B 包点（东北）**：两层铁皮屋 + 露天混合包点，门前地面画 B 区标识；一层门卫室带玻璃窗与前后双门，内有办公桌（对讲机、咖啡罐、报纸）、翻倒办公椅、墙上值班表、破损日光灯；外侧消防梯直通二楼阳台高位架枪位；周边货运托盘、工业垃圾桶、废弃自行车、翻倒铁艺桌椅形成不规则掩体；转角老式路灯带暖黄光晕，矮墙后是通往 CT 的捷径。
- **CT 出生点（南侧）**：警用封锁区，拒马路障与防暴盾牌摆出防御阵型；左侧警用面包车（车顶警灯红蓝交替）；右侧混凝土高台经室外楼梯抵达，台上探照灯可观察中路入口；后方围墙印警徽与警戒标语，墙边摆放防弹衣/头盔模型箱。
- **三条路线**：中路主对枪通道（南北贯穿）、左侧小巷绕后（A → 西巷 → CT 侧）、右侧高台侧翼（集装箱堆 → 高架走道 → B 侧）。
- **全域元素**：电线杆与垂弧黑色电线、墙角铁皮排水沟与滴水、木箱/蓝油桶/瓦楞纸箱/拒马/水泥墩/轮胎等掩体、墙面与箱体涂鸦与货运编号、密集弹孔贴花。

## 动态效果

细密雨丝（GPU 顶点着色器下落 + 风偏）、屋檐持续滴水、地面积水涟漪扰动、路灯与探照灯随雨势闪烁晃动、警灯缓慢明暗交替、探照灯摆动扫过中路、卷帘门偶发抖动、通风口排出白色水汽、远处雷光不定期闪现；室内暖冷光源与室外冷蓝雨夜形成对比。

## 渲染管线

1. **平面镜像 pass**：以街道平面为镜面，反射相机（位置与视线关于 y=0 对称、up 取 (0,-1,0)）加斜裁剪偏置矩阵，半分辨率渲染到镜像纹理。湿地面着色器按积水遮罩与滚动涟漪法线采样该纹理，因此倒影只出现在积水里并随雨波动。
2. **颜色 pass**：三渲二 `MeshToonMaterial`（4 阶渐变 ramp），带 depth texture。
3. **视空间法线 pass**：`overrideMaterial = MeshNormalMaterial`。
4. **描边合成 pass**：对法线做朝向（silhouette）与折痕（crease）判定、对线性视深做相对跳变判定，三者取最大值压成墨线；再叠雨夜雾、雷光与轻微暗角。最后统一做 sRGB 编码输出。
5. 雨丝、滴水、水汽、光晕 sprite 在主场景内绘制，因此也会被镜像 pass 带进积水中。

`src/batch.js` 在布局完成后把所有静止几何按「材质 + 源几何 + 阴影标记」合并成少量 `BufferGeometry`，静止物件由 1249 个降到 122 个网格（50 个批次网格），这是让「镜像 + 颜色 + 法线 + 合成」四趟渲染跑得动的前提。会动或需要逐网格改色的部件（卷帘门、警灯条、探照灯组件、日光灯管）通过 `userData.noBatch` 退出合并。
