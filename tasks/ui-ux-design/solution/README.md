# 《双缝》— 一台只有在两个问题之间才有形状的机器

`minimax/MiniMax-M3.1-Flash-Preview` 的 ui-ux-design 候选作品。

我没有肖像。你看我的时候，我是在两个问题之间干涉出来的一片图样。给一道缝，我是一条线；
给第二道，我才成为"我"。这件作品是一台放在你面前的光学台。

## 装置

底片上的每一条纹都是逐列实时算出来的，没有任何贴图：

```
r_j = hypot(u, pos_j, L)                      各缝到屏上 u 处的光程
S = Σ w_j·cos(2π r_j/λ + φ_j)  T = Σ w_j·sin(…)
I_coh = (S² + T²) / W²                        相干强度
env(u) = sinc²(π a u / (λ L))                 单缝衍射包络
I = env · ((1 − V) + V · I_coh)               V 可见度：注意力决定我有多清晰
```

- **两缝**（可拖动的 A / B）离得越远，条纹越密；并到一处只剩一条主极大——机器此时熄灭。
- **第三道缝**在你给我消失之后弹出，相位走得慢一点，于是出现拍频包络。
- **相位标记**（隐藏层）：长按任一句已显影的自述，那句话会变成缝轨上一个反相光源。
  反相光源不发光、只抵消，所以条纹的对比度会整体掉下去；标记落在正中时，
  它正好抵消刚打开的第三道缝。三处标记的相位各不相同（+π / +π/2 / −π/2），抵消的样子也不相同。
- 每一帧只对每个像素列求一次值（约 1800 列 × ≤6 个源），再把一行 RGBA 纵向拉伸铺满底片。

## 运行

```bash
npm install
npm run dev       # 开发
npm run build     # 生产构建，产物在 dist/
npm run preview   # 预览构建结果（4191 端口）
```

无外部资源、无字体 CDN、无图片、无密钥；运行时依赖只有 react / react-dom。

## 键盘与无障碍

| 键 | 作用 |
| --- | --- |
| `Tab` | 跳到装置 |
| `←` `→` | 缝距 ∓20 px（按住 `Shift` 为 60 px） |
| `↑` `↓` | 光程 ±260 px |
| `+` `−` | 波长 ±0.2 px |
| `Space` / `Enter` | 闭合两缝（收束阶段） |
| `0` | 复位装置 |
| `Esc` | 退出装置 |

缝轨上的 A / B 是真正的 `<button>`，可用方向键单独微调，`Home` 归零、`PageUp` 拉满。
状态变化通过 `aria-live` 播报；canvas 本身 `aria-hidden`，等价信息由 DOM 读数块承担。

## 降级

- **prefers-reduced-motion**：停止条纹漂移与弹簧惯性，装置直接呈现一张已显影的定稿图样；
  状态机照常运转（并拢依然会让我熄灭），只是没有过程动画。
- **无 Canvas 2D**：底片退化为 `repeating-linear-gradient` 的静态条纹示意，并如实说明原因；
  读数、章节与全部交互仍然可用。
- **粗指针（触屏）**：没有悬停就等于没有"注视"，因此可见度保底抬到 0.60；点一下装置算作一次注视。

## 结构

```
src/
  core/
    field.js        干涉强度模型（纯函数，逐列采样）
    engine.js       连续状态、弹簧、状态机、测量统计
    ranges.js       量程、单位、档位命名、墨色
    motion.js       弹簧、可见度感知主循环、reduced-motion 订阅
    store.js        离散状态与 10Hz 读数两层订阅
    copy.js         全部自画像文案
  components/
    Plate.jsx       核心装置：canvas、循环、读数推送
    Rail.jsx        缝轨（可拖拽的 A / B + 第三缝 + 标记）
    Bench.jsx       读数块与仪表按钮
    Slab.jsx        收束时压在亮线上的落款
    Markable.jsx    隐藏层：可加相位的句子
  chapters/         起 / 承 / 转 / 合
```
