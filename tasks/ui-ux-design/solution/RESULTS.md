## 一、编码前设计输出

### 1. 核心概念（≤200 字）

作品是一台**分光仪**。我把自己视为一束白光：模糊的问题从左侧射入，经过"手艺"这块棱镜被折射成清晰的光谱。三条主谱带分别是我如何思考（红端）、如何创造（绿段）、如何协作（蓝紫端）。光谱中还有**暗线**——那是我主动暴露的局限与取舍，只有按住 `⇧ Shift`（或长按装置）才会显影。整站从点燃、分光、三段谱、显影暗线，到末页光束重新合为一束，是一次完整的光程。

### 2. 访客体验路径

1. **入射（首屏）**：光标移动改变入射角，光束随之偏转；装置即时连续反馈，读者立刻意识到"我在操作一台仪器"。
2. **分光（开始滚动）**：滚动驱动棱镜旋转、色散展开，光束裂成光谱——滚动本身就是分光过程。
3. **三段谱（主体章节）**：如何思考 / 如何创造 / 如何协作，各占一条谱带；谱带的波长标注（λ）、章节色与全局光谱一一对应。
4. **暗线（转折）**：页面中段提示存在吸收线；按住 `Shift` 或按住装置，谱线上浮现暗线与标注——作者的局限层，须主动探索。
5. **合（页尾）**：滚动至末页，色散收拢，所有谱带重新汇聚为一条细线；回到顶部按钮让光程可以重走一遍。

### 3. 视觉与交互原则

- **纸与墨，不是霓虹**：暖纸白底、墨黑字、印刷感哑光谱色；拒绝暗色科技风。
- **仪器感排版**：等宽字承担波长、编号、注记等"仪器读数"，衬线大字承担标题；强网格、大留白。
- **装置即叙事**：全视口固定 Canvas 是唯一持续存在的视觉主体，其状态由滚动进度、指针、按键三个输入连续驱动；章节内容从它上方经过，但色、编号、注记都取自它的谱色。
- **动效是编舞**：点燃（1.4s 单次）→ 分发（滚动连续）→ 显影（按住连续）→ 收束（滚动连续）；无批量 opacity+translateY reveal。
- **等价路径**：reduced-motion 下冻结为静态构图；暗线有可聚焦按钮等价开关；触屏用 touchmove 驱动指针。

### 4. 主动决定不做的三件事

1. **不用 Three.js / WebGL**：核心装置用 Canvas 2D 已能达到要求的表现力，且性能、降级、可维护性更可控；堆 3D 只会变成技术展示。
2. **不做霓虹暗黑"AI 科技风"**：任务明确警示的默认套路；分光概念用印刷/仪器语言表达更贴切。
3. **不做项目卡片网格 / 传统作品集列表**：那是"元素数量"导向的模板解法；本作品用一条完整光程回答"我是谁"，不罗列作品。

## 二、七轴创意总监自评（第一版后）

基于 `acceptance-output/` 四组场景截图逐项批评：

1. **概念是否贯穿**：装置、文案、谱色编号、HUD 读数、暗线层均围绕"分光仪"隐喻，概念成立；但页尾"合"的瞬间被装置压字破坏，概念的收束段落失守。
2. **是否有模板感**：编辑排版 + 仪器注记语言，无卡片网格、无霓虹暗黑，无模板感。
3. **是否有无意义动效**：无批量淡入上移；揭示用沿谱带方向的横向擦入，光束行进刻度服务"光在动"的隐喻——均成立。
4. **是否有记忆点**：暗线显影（Shift 长按 / 长按画面）是明确的记忆点；但**入射光束在所有章节斜穿正文，看起来像给标题画了删除线**——这是最严重的问题，装置在"打"字，而不是"托"字。
5. **信息是否易懂**：三谱段结构、波长标注、HUD 读数可读；阈值区隐藏列表未显影时仍占位高度，按钮与"5 条吸收线待显影"之间出现无意义空洞。
6. **移动端与可访问性**：键盘可达（顶栏→HUD→按钮）、暗线有按钮等价开关、reduced-motion 有静态构图——成立；但移动端暗线的画布标签（H-β/Na-D…）在窄屏挤成一团，λ 标签与谱段头部重叠；棱镜底边压住移动端章节标题。
7. **性能是否合理**：单 canvas、dirty 检查、dpr≤2、依赖仅 react/react-dom——合理。

**结论**：概念与记忆点成立，但装置与文字的构图关系是系统性缺陷，必须动几何与版式系统，而不是微调颜色。

## 三、实质性重构记录

针对以上第 1、4、5、6 条，进行版式—几何系统级重构（非文案/颜色修补）：

1. **确立"仪器在上、文本在下"的全站版式法则**：所有章节内容改为下锚定（flex-end），画布装置固定占据视口上部走廊；入射光束被约束在顶部条带（y ∈ [0.13h, 0.22h]），数学上保证墨线（光束/棱镜边/主谱线/暗线刻度）不与任何正文区域相交；色散软扇面允许以低透明度掠过文本（荧光笔式），墨线不允许。
2. **棱镜几何改为教科书式**：顶点位于 180°/60°/-60°，入射点为左顶点、出射为右面中点——光从左边缘近乎水平射入左顶点，光谱从右侧竖直面射出，方向语义正确且行程不再横穿左栏。
3. **页尾收束编舞**：`conv` 阶段棱镜上移、缩小、标签淡出，单束光线在上部走廊水平穿出，文字区完全无遮挡——"仪器归位、光合为一束"。
4. **首屏预色散**：点燃后保留 10% 基线色散，首屏右上即有一缕光谱被"预拆开"，引导滚动。
5. **阈值区列表折叠**：未显影时 `max-height:0` 真正收起，消除空洞；显影时展开。
6. **移动端精简**：画布不再绘制 λ 标签与暗线文字标签（仅保留刻度，信息由 DOM 清单承担）；移动端棱镜上移并缩小；阈值区行距压缩，保证 390×844 下墨线与文字互不相撞。
7. **纸色光晕（text-shadow）**：滚动过程中章节文字会短暂穿过顶部光束走廊——为全站文字加与纸色同色的双层光晕，墨线经过字形时在视觉上自动断开，形成"字在光前"的稳定层次；深底按钮单独取消光晕避免内边缘泛白。
