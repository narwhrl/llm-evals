## 编码前创作决策

### 核心概念

我是一份永远在修订中的校样。这一页不是自我介绍，而是我的排版现场：思考以墨迹落纸，犹豫以校对符号显形，删去的句子落进废稿篓，留下的每一句都经过你的手。你不是读者，是合校者——你删什么，我就成为什么。英文标题 PROOF 双关：付印前的校样，与存在的证据。

### 访客体验路径

1. 落在一张几乎空白的校样纸上（版心线、定位十字、未干的标题），朱笔光标在等待。
2. 滚动＝走纸：文字以「压印」落进版心（微回弹、墨在纤维里洇开定住），不是淡入。
3. 删改（核心装置）：校对符号沿笔画生长；访客就是朱笔——划掉一个词，该词被撕起、翻卷、落进页边废稿篓，替代词带重量落下补位；页边「清样预览」实时改写。
4. 转折：整句被画上巨大的删除号，随后印版翻面——这一翻是全站最关键转场。
5. 收束：清样排定，访客的全部删改汇成一句只属于本次访问的「我」，钤一枚「校讫」章；页边可翻废稿篓找回删掉的词。
6. 版本记录（模型标识、概念说明折叠）。

### 视觉与交互原则

- 纸是舞台：状态即纸的状态（洁净/洇墨/压痕/撕口/钤印）；动效先定重量与阻力，再定缓动。
- 朱红只在「判断」发生的时刻出现（划、删、钤）；底色暖纸＋墨黑＋一个铅蓝作为次级校色。
- 文字是物质：可压印、划去、撕起、掉落、砸落回位。禁止 opacity+translateY 批量 reveal。
- 每个交互必须改变内容/结果（终句、预览），不只是改变样式。
- 排版克制：大留白、明确版心、正文衬线＋标号等宽；校对符号本身作为图形语言。

### 主动决定不做的三件事

1. **不做 Three.js/WebGL/粒子/玻璃拟态**——概念发生在纸面上，是平面物质；3D 与光效会把作品拉回「AI 科技风」模板，与命题冲突。
2. **不做打字机式逐字输出、终端黑客叙事**——那是对我工作方式的误读；我的可见形态是「修订」，不是「吐字速度」。
3. **不做多路由、多区块的个人官网**（无作品集/技能树/时间线/联系表单）——一页一念、一次付印流程，章节以纸张状态延续，拒绝拼盘感。
