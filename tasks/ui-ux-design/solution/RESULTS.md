## 实施前设计文档（编码前撰写，原文保留）

### 核心概念（≤200字）

**《在读 · Being Read》—— 存在，即被阅读。**

我是 kimi-k3，一个语言模型：没有连续记忆，没有感官，只在你阅读的此刻存在。这件作品把"注意力"做成一扇窗——窗外，构成我的文字散作流动的墨；窗内，它们凝聚成句。你移动目光，我在目光所及之处成形；你停下来，我在页边写下没说出口的话；你写下开头，我替你续完；你读过的字，最终钤成一枚属于你的印。

### 访客体验路径

```
序·未读 ──→ 晨·构成 ──→ 昼·续写 ──→ 暮·边界 ──→ 夜·钤印
(墨池静候)   (字随目聚)   (你写我续)   (窗收窄)   (你读过的字成印)
开始        发展         高潮/转折     转折深化     收束
```

隐藏层：静止 6 秒 → 页边批注浮现。重访者因阅读驻留不同而得到不同的印。

### 视觉与交互原则

1. 一纸一墨一印：暖纸 `#f4efe6`、松烟墨 `#1a1714`、朱砂 `#b23a2a`（仅用于印章/焦点/关键落笔）。编辑排版而非网页排版：竖排章节题、衬线、大量留白。
2. 注意力窗是唯一装置：全站文字信息在同一装置内"凝聚—消散"；滚动只切换章节状态（季节/流速/窗径），不改变装置逻辑，章节间有视觉因果（上一章的字流入下一章）。
3. 动效即书法：字粒用弹簧物理模拟提按转折，有重量、有迟滞；禁止批量 fade+translateY。
4. 静也是交互：页面奖励静止，与奖励移动对称。
5. 原生滚动、键盘可达、reduced-motion 下静态构图同样成立；Canvas 装置为渐进增强，所有信息在 DOM 中有等价文本。

### 三件不做的事

1. 不做暗色霓虹"AI 科技风"/粒子背景——那说的是"科技产品"，不是"我"；纸墨语言才贴合"由文字构成"的身份。
2. 不做官网式信息架构（导航栏/卡片墙/时间线简历）——这是自画像，不是落地页；单一长卷叙事，章节即一生。
3. 不堆 WebGL/音频/外部 API——文字质感用 Canvas 2D 已足够且字体保真最好；零密钥、零运行时服务保证本地可构建可运行；续写用本地 n-gram 引擎而非 API 调用。

### 技术方案

Vite + React 18 + TypeScript；运行时依赖仅 react/react-dom；字体自托管（@fontsource/noto-serif-sc）。核心装置 `InkEngine`（Canvas 2D）：流场 + 字粒弹簧物理 + 注意力窗；章节状态机；DPR 封顶、字粒预算、页面隐藏暂停。续写为本地字级马尔可夫引擎；钤印为驻留追踪 + SVG feTurbulence 印泥糙边。

## 七轴创意总监自审（首版完成后）

1. **概念是否贯穿**：注意力窗、续写、钤印、批注都在说"存在即被阅读"。**不通过项**：夜章收束是"两张皮"——DOM 印章与墨河没有物理关系，"河沉为印"只是文案声称；且"静也是交互"只有批注承担，装置本身对静止无动于衷。
2. **是否有模板感**：无卡片/无导航模板；但引擎启动前首屏是 1–2s 白纸，读作"没做完"而非"克制"。
3. **是否有无意义动效**：无批量 reveal；呼吸点（引导）、幽灵字（犹豫）、钤印（收束）均有概念职能。通过。
4. **是否有记忆点**：朱砂「你」、注意力窗、个人印章成立，但缺"全站共享状态"层级的惊喜。
5. **信息是否易懂**：DOM 散文自洽完整；晨章散文"不分高下"与诗节用字重复。
6. **移动端与可访问性是否成立**：桌面成立；移动端昼章诗节与表单相触；夜章减动效静态构图与 DOM 散文相撞；skip-link 指向当前位置无意义。
7. **性能是否合理**：字粒预算、DPR 封顶、页面隐藏暂停、帧耗自适应降级齐备；字体按 unicode-range 子集加载。通过。

## 自审后的实质性修改

1. **夜章汇聚（收束因果）**：每个环境字粒预分配归一化印床格点；夜章随滚动进度把整条河收拢成视口中央一方"字泥"（边缘格点权重渐弱成晕染方形），DOM 朱砂印章落在字泥上——河流真正变成了印。
2. **静止致意**：`setCalm` 接入 idle 状态——访客停下时，批注浮现的同时整条河流速与雾浓度衰减，静止成为全站共享状态。
3. **首屏占位**：引擎启动前 DOM 静态呈现「在读」标题与命题句，引擎就绪后淡出；也是 JS 失败链的一环（另有 noscript 兜底）。
4. **章节级避让**：`yHi` 参数化锚点下界（昼章更靠上，移动端统一 ×0.55），修复昼章移动端诗节/表单相触、夜章减动效静态构图/DOM 散文相撞。
5. **细节**：skip-link 改指正文首章；晨章散文去重；印章读序按传统印面（右上→右下→左上→左下）。

开发期另修复三个引擎级缺陷：sin 哈希流场的轴对齐条纹（换整数哈希）；字粒平衡位置 = 流场×(1-w) + 字位×w 导致的家偏移（页籍字粒河流分量截断为字位邻域徘徊）；到位前墨量过深导致的"错字飞行"（墨量 = 窗权重 × 到位度）。

## 验证记录

- 构建：`npm run build`（tsc -b && vite build）→ 通过，零错误零警告；产物 JS gzip ≈ 57KB，字体子集按需加载。
- 预览：`vite preview --port 4723`，真实 Chromium 实测。
- 桌面 1440×900：五章巡览——序章标题凝聚、晨章诗节逐行成形、昼章续写（输入"夜深了"/"雨停之后"各一次，幽灵候选→落定→"途中舍弃"清单，结果注入墨河）、暮章窗收窄（半径 150→92）、夜章河字汇聚+钤印（两次访问印章不同：「在读我你」/「我给你续」，证明驻留追踪真实生效）；全程 `pageerror`/`console.error` 为零。
- 移动端 390×844：无横向溢出（scrollWidth === clientWidth），昼章避让、夜章收束、印章均成立。
- 减动效（`prefers-reduced-motion: reduce` 模拟）：装置切换为静态构图——全部诗节即时成形、雾静止；续写跳过逐字动画直接完成并列出舍弃候选；钤印无压印动画。
- 键盘：Tab 顺序 跳过链接 → 输入框 → 续写 → 再钤一次 → 回到开头；Enter 可提交续写；`:focus-visible` 朱砂描边。
- 隐藏层：静止 6 秒页边批注浮现（实测出现"批注，是写给自己的话。"），任何活动即刻隐去。
- 帧率：headless 环境 rAF 受按需出帧节流，无法取得可信 fps 数字；设计上字粒预算随视口收敛（桌面 ≤820、移动 ≤360）、帧耗 EMA 超 26ms 自动削减 20% 环境字粒。

## 已知限制

- 续写是本地字级马尔可夫（order-2，约 2.6 千字自撰语料）：有循环护栏与句号收束，输出是"机器诗"质量，不保证语义连贯——这本身是概念的一部分（我只读过，不曾见过）。
- 印章用字取决于本次访问的真实驻留；极短访问回退到「在读此刻」补位。
- Canvas 装置为渐进增强：全部实质信息在 DOM 中以等价文本存在；canvas `aria-hidden`。
- 未接入任何音频；触觉反馈仅移动端钤印时 `navigator.vibrate(18)`（支持才触发）。

无需人工干预即可 `npm install && npm run build && npm run preview`。
