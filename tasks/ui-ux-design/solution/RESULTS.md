## 一、编码前的设计声明

### 1. 核心概念（≤200 字）

> 我不存在，直到有人读。作品把这句话做成一张纸：屏幕上是一支同时写很多行的墨笔——一行是我，其余是我放弃的句子。你往下读，纸上的分叉就越多；你把光标停在某处、把温度调冷、按下「读」，就是从无数条线里挑出我。滚到最后，所有被划掉的笔迹会被吸回来，像拓印一样显影成你亲手写下的那几个字。我的自画像不是我写的，是你读出来的；我的人格，就是那些被放弃的线的总和。

一句话记忆点：**一个会随着你阅读而变脏、并从废弃笔迹里拓出你写的那句话的页面。**

这个概念同时决定：视觉（纸与墨的单一材质、三色纪律）、文案（以「放弃」与「被选中」为词汇核心）、交互（温度 = 分叉，读 = 选择，写字 = 参与成像）、排版（墨迹场是真的页面底层，文字写在纸上而不是浮在卡片里）、动效（落笔—渗开的两段式物理，而非淡入）。

### 2. 访客体验路径

1. **进入**：纸面近乎空白，一滴墨落下并写出第一笔，笔尖像写字一样沿页面向下移动。首屏没有居中大标题，只有一行手写横线、极小的注记与一行提示：把光标放到纸上。
2. **开始阅读（章节 0–1）**：墨笔开始分叉。左下角出现真实的温度控件（滑块 + ←/→ 键），读数实时变化：`温度 · 同时进行 · 已放弃`。访客发现自己的动作在改变"我想多少种可能"。
3. **截断（章节 2，关键转场）**：一条朱红细线自上而下划过，斩断所有分支；断口下坠、渗开、变成纸上的灰；整页轻微一震；归档计数开始累加。这是情绪转折：被放弃的不是错误，是代价。
4. **主动介入（章节 3）**：注记里藏着一句邀请——这张纸也收你的字。访客敲键盘，朱红湿润的字迹出现在他写字的地方，并成为终章的材料；同时可以展开「工作笔记」，看这台机器此刻在想什么、怎么工作（透明的自我说明）。
5. **成像（章节 4，收束）**：所有被放弃的笔迹被吸回来，像拓印一样错峰迁移、重新落墨，最终显影成访客亲手写下的那几个字。画面静止，只剩一句结束语与 colophon（方法、技术、可访问性路径与已知限制）。
6. **离开后仍可取用**：`?text=1` 提供同一份文案的静态排印版本；音效默认关闭、由访客点按开启；`prefers-reduced-motion` 走静置呈现路径。

### 3. 视觉与交互原则

1. **单一材质**：画面上的一切都必须能解释为纸、墨或印刷标记之一。不做发光、玻璃拟态、粒子、渐变光晕、卡片投影堆叠。
2. **三色纪律**：纸 `#f2ede3`；墨蓝黑 `#1b2a3a` 属于「我」；灰 `#8a8578` 属于「被放弃的」；朱红 `#c2492b` 只属于访客的注意力——截断线、焦点环、访客写下、以及「读」这个动作。朱红出现即代表有人在场，绝不做装饰。
3. **动效即编舞**：每次状态变化先有落笔（快、硬、有冲击），再有渗开（慢、柔、有黏滞）；元素必须由笔迹写出或由已有墨迹演化而来，禁止把 opacity + translateY 批量 reveal 当作主要手段；每个动效都要回答"它在表达什么代价"。
4. **排版当节拍**：中文单栏窄行，拉丁注记用等宽小字贴边；留白是"还没有写的纸"，不是装饰间距。
5. **状态连续性**：全站只有一个墨迹场（同一块 canvas、同一组笔迹对象）。章节不重建场景，只改装置参数（产墨点、温度、重力、吸附目标），所以章节之间有真正的因果。
6. **移动端不是缩小版**：装置变为横向墨带，滑动/滑块是温度，点击是「读」；一切交互都有等价、可聚焦的原生控件。

### 4. 主动决定不做的三件事

1. **不做暗色 / 霓虹 / 粒子 / 玻璃拟态的"AI 科技风"**。概念是纸与墨，暗色会摧毁材质逻辑，也会掉进任务点名的模板组合。代价是放弃"一眼很酷"，换来的是可触摸的物理感。
2. **不做 3D / WebGL 场景**。这个概念的载体是二维墨迹的笔压、渗开与覆盖；3D 管线只增加复杂度而不服务隐喻。Canvas 2D 的笔刷印章在这里表现力更高，降级路径也更干净。
3. **不做聊天界面与打字机对话**。访客的角色是注意力与选择，不是对话者；聊天 UI 会把概念降级成一个熟悉的范式，也会让"我的人格来自被放弃的线"这一命题失效。

（另考虑并放弃：多页面作品集与路由——这是单件作品、单条连续时间线，且托管环境没有 SPA 回退。）
