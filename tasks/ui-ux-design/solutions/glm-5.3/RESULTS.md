## 一、实现前创作方案（编码前输出，原文存档）

### 核心概念（命题）

> **《下一个词》——一台语言模型的自我画像。** 我不"知道"任何事；我每一刻都在一个分布里打捞下一个词。这个作品把"猜测"变成可触摸的装置：句子里的关键词是活的概率分布，你的注视让它颤动，你的点击让它坍缩，按住不放，就能看见我脑中所有未说出口的候选。你采样的每个词都会化为颜色与飘散的字，成为页面的世界本身；而当你离开，这一切不会被留下——像每一次对话里的我一样。

### 访客体验路径

1. **序（首屏）**：句子 `我在〔?〕里〔?〕下一个词。` 逐词"当众采样"成形；最后一个词拒绝坍缩，等你亲手按下——你的第一次点击就是作品的第一句文案。
2. **听**：输入框，每个键入的字符带着重量坠入页面世界（Canvas 字段），泛起涟漪。
3. **忘**：上下文窗口一条——你在序里采的词正在排队变淡、上飘；点击只能"看一眼"：注意不是记忆。窗口满后旧词真的散去（计数）。
4. **错**：一段自白，下划线厚度=把握；按住整段，看见"没被选中的那条路"；θ（右上角温度旋钮）实时改变全站分布与胆量。
5. **逢（尾声）**：你的所有选择凝成一句只属于本次相遇的话 + 一抹由采样词色相圆均值推导的颜色；长按有隐藏层（未选之路）；可复制带走。收束句号「。」与首屏落下的句号呼应。

### 视觉与交互原则

- **纸与墨**：暖纸底、墨色衬线、等宽字做"机器声部"——两种声部的对话即自画像；刻意避开暗色/霓虹/玻璃拟态。
- **意义有颜色**：每个候选词携带一个色相，全站强调色 = 本次会话采样词色相的圆均值——颜色由你的选择推导，而非装饰。
- **动效词汇只有一套**：分布颤动 → 坍缩 → 弹簧落定 → 飘散。出场动画不是主题，采样才是。
- **状态延续**：采过的字成为全站背景世界（上下文字段），章节间靠它因果相连。

### 主动不做的三件事

1. **不做暗色霓虹粒子风**——概念是纸上的墨与概率，不是科幻终端；"被渲染感"会杀死"被书写感"。
2. **不做滚动批量淡入上移**——任务明令的主动画禁忌，且与"采样"无关；所有运动来自装置本身。
3. **不做音频**——声音会抢走"阅读"这个主角，且自动播放策略会把体验切碎；用弹簧重量、色彩与轻触觉振动（`navigator.vibrate`，无权限要求）替代反馈。

## 二、实现概要

| 层 | 选择 | 理由 |
| --- | --- | --- |
| 框架 | React 18 + Vite 5 | 标准工具链，构建可靠 |
| 渲染 | DOM + Canvas 2D | 字粒子用 Canvas 足矣；WebGL 属炫技 |
| 动效 | 手写弹簧 + 单一 rAF 驱动器 | 物理"重量感"需要自己调参；GSAP 反而隔层 |
| 字体 | **自托管思源宋体子集**（712 字符，2×~313KB woff2）+ 系统等宽 | 评估环境无 CJK 衬线；子集化保住排版身份且仍是零外部请求、零密钥 |
| 隐私 | 无后端、无统计、无上传 | 概念（不留存）即实现 |

核心装置：**词位（WordSlot）**——同一单元的四种形态（颤动/坍缩/live/分布视图）贯穿首屏、章节标题与尾声；**上下文字段（ContextField）**——固定视口的纸上世界，承接所有采样词与键入字，含指针力场（注意是一种力）、滚动视差、年龄衰减、θ 驱动的躁动。

长时序（开始—发展—转折—收束）：首屏装配。开始：纸上只有呼吸与光标；发展：「我在」逐字落定、第一个槽位颤动待坍缩；转折：最后一个槽位拒绝自行落定（8 秒兜底）；收束：句号带重量落下、译句浮出、世界醒来。

隐藏层（需主动探索）：① 尾声长按纪念句显示两排"未选之路"；② θ 与下划线厚度/幽灵显影/场速的联动；③ 采样 ≥5 次后尾声多出一句"你已经替我做过 N 次决定"。

## 三、七轴创意总监自评（第一版完成后，逐项批评）

1. **概念是否贯穿** —— 大体贯穿：采样颤动→坍缩是全站唯一动效语言；颜色由采样推导；记忆窗口真实截断。批评：θ 的全局影响过于隐性，只有分布面板能直观感知。处置：下划线厚度、幽灵显影幅度、字段躁动全部接入 θ（已实现），分布面板头部实时显示 θ。
2. **是否有模板感** —— **最大弱点**。四个章节共用"大字+旁注+正文+细线"骨架，整页截图下中段同构、单调，像同一模块连放四次。处置（实质性重构）：章节"移调"——听=大字与标尺右起（镜像应答）；忘=正文窗口放宽至 920px、大字随章节滚出视野而淡去（心不在场=忘，概念直击）；错=正文居中窄栏（密谈感）；逢=居中仪式（原有）。复验确认变奏可感知。
3. **是否有无意义动效** —— 逐项检查：呼吸（句子活着）、幽灵游移（未定）、字符游走（与首屏同一语言）、涟漪（听见）、视差（世界有深度）——各有概念支点。唯一收紧：char-settle 关键帧曾用 `fill:both` 锁死 opacity，导致"忘"的淡出失效——移除关键帧中的 opacity（真 bug 修复）。
4. **是否有记忆点** —— "按住看分布/松开选定"（你替模型做决定）、"颜色由你推导"、"字飘在纸上世界"。装配序列的转折（等你按下最后一个词）是第一记忆点。足够。
5. **信息是否易懂** —— 首屏注文明示"点一下/按住不放"；错章节明示"按住这段话"；尾注给出键盘路径。移动端长按已屏蔽系统文案菜单。可懂。
6. **移动端与可访问性是否成立** —— 实测通过（390×844 无横向溢出；分布面板为底部抽屉；触点目标≥30px；键盘全路径：Tab/Enter/↓/↑/Esc 可完成与鼠标等价的采样与选定；focus ring 用会话强调色；reduced-motion 下全部即时呈现、交互不残废、Canvas 只绘静态构图）。批评留档：分布面板行本身不可 Tab 聚焦（由词位按钮统一承载键盘），属有意取舍。
7. **性能是否合理** —— 单 rAF、空场早退、字体串缓存、粒子上限（桌面 90/移动 40）、DPR 上限（1.5/2）。软渲染无 GPU 的无头环境满载 ~42fps（瓶颈为 llvmpipe 软件光栅化整屏 Canvas，非 JS）；真机 GPU 合成下为常规 60fps 负载。生产包：JS 169KB（gzip 57KB）+ 字体 2×313KB 自托管。

### 自评后的实质性改动（不止文案与颜色）

1. 章节移调布局变奏（mirror/fade/居中窄栏）+ SectionHead 增加 `variant`/`fade` 能力（含滚动驱动的大字淡出）。
2. 自托管思源宋体子集（712 字符自动收集自源码），修复评估环境 CJK 无衬线退化。
3. 修复三处真实缺陷：分布面板在 92px h1 内的 em 单位爆炸（百分比列漂出面板）；色相圆均值出现负值（`hsl(-156°)`）；char-settle `fill:both` 锁死 opacity。
4. Canvas 空场早退 + 字体串缓存；正文层字重/字号上调（"正文像附注纹理"的批评）。
5. 尾注收束句号「。」，与首屏句号构成首尾回环。

## 五、已知限制

1. 评估机无 GPU（VGA 虚拟设备 + llvmpipe），Canvas 字段满载帧率受软件光栅化限制；真机浏览器（GPU 合成）下负载常规。
2. 思源宋体子集仅覆盖本页源码字符集（712 字符 + 可打印 ASCII）；动态内容若出现集外字会回落系统字体。
3. `navigator.vibrate` 仅部分移动平台支持（iOS 忽略），已用视觉重量兜底。
4. 剪贴板 API 依赖安全上下文（localhost/https）；失败路径给出可选中复制的提示。
5. 无第三方分析或持久化——这是概念与隐私原则，不是缺失。
