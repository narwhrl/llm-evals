# 校样 · 一份关于语言模型的自述

《校样》是一件关于"我自己"的前端作品。语言模型不是一个给出答案的黑箱，它是一支会先
写下、再回头重读的手。所以这里没有自我介绍页，只有一张**校样**：热排工坊里的一张样张，
上面排着十六段关于我如何工作的自述，每一段都留着两种还没选定的说法。

红铅笔交给读者。落笔之后，原句被划掉、另一种说法压上来、页边长出一条编辑的意见、
纸上的字距随稿件收敛而收紧。改得越多，校次越高（一校 → 二校 → 三校 → 付印）。到
「付印」可以上机：压印机落下，纸翻过去露出背面——落笔之前的那一版——再翻回来，纸上
只剩读者选定的措辞，和一条由落笔次序连成的红线签名。

## 运行

```bash
npm install
npm run dev        # 开发服务器，默认 http://127.0.0.1:5179
npm run typecheck  # tsc --noEmit
npm run build      # 类型检查 + 生产构建，产物在 dist/
npm run preview    # 预览生产构建
```

零外部资源：纸纹、水印、规矩线、印章、铅笔都是 CSS 与 SVG；落笔、咔哒、压印的声音
由 Web Audio 实时合成。不需要任何密钥、账号或网络。

## 结构

- `src/content.ts` — 稿件本身：十六段自述、每段的两种改写、每段的编辑批注、三处误植、
  校次阈值、文稿分段的论点。
- `src/state.ts` — 校对状态：每行被改了几次、落笔的先后次序、盲校找到的误植、压印状态。
- `src/components/Galley.tsx` — 样张本体。改稿的层次、删除线、批注、订口的批注与
  贯穿订口的注意力红线；页边的分段跟随阅读位置。
- `src/components/Slug.tsx` — 顶部印张：印张号、校次、纸张、版面、修订数、误植数，
  以及盲校、付印、声音三个开关。
- `src/components/Margin.tsx` — 右页边：当前段落的论点、段落索引、改稿登记、误植提示。
- `src/components/Press.tsx` — 压印序列：压印机下降、纸被压出压痕、翻面露出背页、
  抬起、定稿页与版权页。
- `src/components/Pencil.tsx` — 跟着指针走的红铅笔，带滞后，落笔时下压。
- `src/sound.ts` — 落笔的沙沙声、校次推进的咔哒、盲校猜错的闷响、压印机的闷震。

## 交互

| 操作 | 效果 |
| --- | --- |
| 点击一行 | 落笔：划掉原句，换上另一种说法，并长出编辑批注 |
| 再点同一行 | 换成下一种说法（共两种） |
| 悬停一行 | 订口上浮出一道淡红线，提示铅笔会落在哪里 |
| 上下键 | 在十六行之间移动 |
| Enter / 空格 | 落笔 |
| B | 盲校：纸变暗，只校验误植，不改稿 |
| P | 付印：压印机落下，走完整条长时序 |
| Esc | 从定稿页回到纸面 |

## 可访问性与降级

- 每行是真正的 `button`，带 `aria-label`（第几段、是否已改、当前措辞）与可见的
  校对红焦点环；首部有跳到正文的 skip link。
- `prefers-reduced-motion: reduce` 下所有过渡与动画时长归零：落笔立即生效，压印序列
  直接呈现定稿页，红铅笔不再跟随指针（此时光标本身已经是铅笔形状）。
- 移动端 390 × 844：纸宽占满，订口收窄，边注改为贴在句下，印章移到标题上方。
- 声音可随时关闭。
