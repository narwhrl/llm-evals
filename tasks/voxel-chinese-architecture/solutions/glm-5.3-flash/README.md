# 体素中国古建筑群 · Voxel Chinese Architecture

Three.js 体素（Voxel）风格中国古典建筑群场景，纯前端、无后端、无远程资源。浏览器打开即见全景。

## 运行方式

```bash
npm install
npm run dev        # 开发服务器，默认 http://localhost:5173
```

生产构建与预览：

```bash
npm run build      # 产物输出到 dist/
npm run preview    # 预览生产构建，http://localhost:4173
```

## 场景构成

中轴对称院落（坐北朝南，南入口在画面 +z 方向）：

- **山门**：城台式门座 + 门楼歇山顶，中央门洞贯通，石狮一对把门
- **主殿**：三层汉白玉台基、五踏大阶、红墙红柱、斗拱带、歇山黄琉璃顶（飞檐翘角、正脊鸱吻），全场体量最大
- **东西配殿**：对称分布于主殿两侧，青瓦庑殿顶
- **钟楼 / 鼓楼**：两座两层方楼，绿琉璃攒尖顶，楼内悬金钟 / 立大鼓
- **宝塔**：主殿后七层青砖塔，逐层收分，塔刹攒尖
- **环境**：红墙灰帽围合、四角墩台；石板甬道与庭院铺装串起动线（山门 → 庭院 → 大阶 → 主殿，支路通配殿 / 钟鼓楼 / 回廊 / 宝塔）；桧柏、花树、灯柱、铜香炉、幡旗点缀

黄昏光影：暖金主光（带 4096 阴影贴图）+ 天光半球光，渐变暮色天空与远雾，ACES 色调映射。灯笼为自发光体素。

## 操作

- 左键拖拽旋转，滚轮缩放，右键平移
- 页面打开即为全景机位，无需任何操作

## 技术

- Three.js 0.170（InstancedMesh 体素渲染，仅输出暴露体素，约数万实例单次绘制）
- Vite 5 构建，纯原生 JS，无其他运行时依赖
