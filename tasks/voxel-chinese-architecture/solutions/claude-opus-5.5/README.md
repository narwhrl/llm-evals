# 体素 · 中轴古刹

Three.js（原生，无框架）实现的体素风格中国古典建筑群。打开页面即为全貌斜俯视，镜头缓慢环绕；拖拽旋转、滚轮缩放、右键平移，任何交互都会停止自动环绕。

## 运行

需要 Node.js 20+。

```bash
npm install
npm run dev        # 开发服务器
npm run build      # 生产构建，输出到 dist/
npm run preview    # 预览生产构建
```

无后端、无外部资源、无密钥。

## 场景

中轴由南向北依次为：

- 山门：歇山顶黄琉璃瓦，中间开拱门，两侧为钉门，门前有一对石狮。
- 前院：东侧钟楼、西侧鼓楼，均为砖台加重檐攒尖顶，墩台开有穿心券洞。
- 中院：东西两座配殿，面向中轴对称布置，歇山顶青瓦，另有横向甬道。
- 主殿：三层汉白玉须弥台基，前有御路踏跺，面阔七间，重檐庑殿顶黄琉璃瓦，檐下挂匾额，殿前设香炉和石狮。

外围是红墙，墙顶覆黄瓦。院内为方砖铺地，中轴甬道用石板，另有草坪、松、柏、银杏。墙外是草地、丘陵和树林。

## 代码结构

- `src/voxel.js`：稠密体素网格，以及可旋转的建筑局部坐标系 `Frame`。
- `src/mesher.js`：剔除相邻面，并计算逐顶点环境光遮蔽，按表面类别输出三个网格（哑光、琉璃、自发光）。
- `src/roofs.js`：基于高度场的屋顶，支持庑殿、歇山、攒尖和重檐下檐，带举折曲线、檐角起翘、鸱吻和宝顶。
- `src/parts.js`：台基、栏杆、踏跺、柱、斗拱与彩画带、匾额、灯笼、石狮、香炉、石灯。
- `src/buildings.js`：主殿、配殿、山门、钟鼓楼。
- `src/scene.js`：地形、铺装、围墙、树木与总平面布局。
- `src/main.js`：渲染器、天空、光照、阴影、相机与控制。

`window.__SCENE__` 是只读的检查句柄（`stats`、`view()`、`home()`、`setAutoRotate()`），用于自动化验收。
