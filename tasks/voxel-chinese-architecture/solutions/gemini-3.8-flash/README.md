# 3D 体素中国古典建筑群场景 (Voxel Chinese Architecture)

基于 **Three.js** 与 **Vite** 构建的高性能 3D 体素（Voxel）风格中国古典建筑群。采用 Minecraft 风格体素块拼接，忠实呈现中式古典建筑的中轴对称布局、斗拱飞檐、重檐歇山顶与古典园林意境。

---

## 🌟 建筑群与场景特色

1. **核心中轴对称布局（共 7 座单体建筑）**：
   - **大雄宝殿（主殿）**：位于中轴线核心核心位置，体量最大。拥有高耸须弥座汉白玉台基、九龙云纹丹陛石御道双阶踏步、五开间朱红漆金立柱、重檐歇山顶、飞檐翘角、双层鸱吻脊兽、殿前双汉白玉石狮以及明代风格悬挂金匾“大雄宝殿”。
   - **东配殿（弥陀殿） & 西配殿（药师殿）**：中庭两侧对称布局，歇山顶黛青琉璃瓦，内向开门，格栅花窗与回廊。
   - **山门殿（前门）**：场地前端入口，设“空门、无相门、无作门”三解脱门三重拱道、歇山飞檐屋顶、山门迎宾石狮。
   - **东钟楼 & 西鼓楼**：前庭两侧对称矗立的双层重檐攒尖顶楼阁，二层平座挑台内分别悬挂青铜大梵钟与兽面大战鼓。
   - **千佛宝塔**：后院东侧五层八角收分木塔，四方券门直棂窗、层层飞檐悬挂铜铃、顶冠五重相轮金刚宝刹。

2. **古典园林与动线规划**：
   - **清晰道路动线**：南向外道 → 山门殿 → 左右放生池与汉白玉石拱桥 → 前庭甬道 → 钟鼓楼 → 中庭青铜大香炉（香烟袅袅） → 丹陛石御道阶梯 → 大雄宝殿 → 月亮门与古松后院塔林。
   - **水系与细节**：前后对称雕栏放生池，浮水荷叶与粉红莲花、白玉拱桥；院落点缀苍劲古松柏云冠；朱红院墙覆黛青瓦顶，设通透月亮门。

3. **高性能体素渲染引擎**：
   - 全场景由 **73,101 个体素** 精确搭建。
   - 采用内部 **六面邻域遮挡剔除算法**（Culling），剔除全部被实心体包裹的不可见内部体素。
   - 采用 Three.js **`InstancedMesh` 批量合并渲染**，全场景仅占用 **34 个 Draw Calls**，即使在低配设备或集成显卡上也能稳定 60 FPS 流畅运行。

4. **光影氛围与交互**：
   - 页面打开即呈现全景鸟瞰视角，无需任何操作即可饱览整个建筑群全貌。
   - 支持 4 种光影时序一键切换：**金辉晨曦**、**午后晴明**、**落霞晚照**、**禅意月夜**。
   - 内置 6 个精心调校的摄像机导览预设视角（全景、山门、中庭、大殿、宝塔、钟鼓楼），支持平滑插值运镜。
   - 支持 OrbitControls 鼠标/触控交互（左键旋转、右键平移、滚轮缩放、自动旋转开关）。

## 🚀 运行方式

### 1. 环境准备
确保本机安装了 Node.js（推荐 Node.js 18+ 或 20+ / 22+）。

### 2. 安装依赖
进入项目目录并执行：
```bash
cd tasks/voxel-chinese-architecture/solution
npm install
```

### 3. 本地开发运行
启动 Vite 本地开发服务器：
```bash
npm run dev
```
启动后终端会提示本地访问地址（通常为 `http://localhost:3000/`），在浏览器中打开即可。

### 4. 生产环境构建与预览
构建生产静态包：
```bash
npm run build
```
构建产物输出于 `dist/` 目录。

本地预览生产构建产物：
```bash
npm run preview
```
终端会输出预览地址（通常为 `http://localhost:4173/`），在浏览器中打开即可验证。

```
tasks/voxel-chinese-architecture/solution/
├── index.html                  # 页面入口与 HUD 控制面板
├── package.json                # 项目依赖与构建脚本
├── vite.config.js              # Vite 构建配置
├── README.md                   # 项目使用与部署说明
├── RESULTS.md                  # 评估与验证报告
└── src/
    ├── main.js                 # Three.js 渲染器、相机、光影预设、交互控制
    ├── style.css               # 玻璃拟态与中式典雅界面样式
    └── voxel/
        ├── constants.js        # 34 种中式古典材质与体素类型定义
        ├── VoxelWorld.js       # 27位坐标压缩存储与六面遮挡剔除 InstancedMesh 引擎
        ├── scene.js            # 建筑群组装与场景灯光集成
        └── builders/
            ├── GroundBuilder.js    # 地面、御道、放生池、拱桥、院墙、月亮门、古松
            ├── RoofBuilder.js      # 歇山顶/庑殿顶/攒尖顶飞檐翘角与鸱吻脊兽数学生成
            ├── DougongBuilder.js   # 柱头科、平身科、角科斗拱与彩画构建
            ├── BuildingBuilder.js  # 大雄宝殿、东西配殿、山门殿、钟鼓楼
            ├── PagodaBuilder.js    # 五层千佛宝塔与相轮金刚宝刹
            └── DetailBuilder.js    # 青铜大香炉、汉白玉石狮、红灯笼
```
