# 体素中式古典建筑群 · Voxel Chinese Architecture

用 Three.js 生成的 Minecraft 体素风格中式古典建筑群。打开页面即进入全景视角，
无需任何操作就能看到完整的院落：中轴对称、山门在前、主殿居中、配殿对称、宝塔收尾。

## 运行方式

需要 Node.js 18 以上。

```bash
npm install      # 安装依赖（three + vite）
npm run dev      # 开发服务器，默认 http://127.0.0.1:5173
npm run build    # 生产构建，产物在 dist/
npm run preview  # 预览已构建产物，默认 http://127.0.0.1:4173
```

无需后端、无需凭据、无外部资源请求：全部体素与天空在运行时程序化生成。

## 场景内容

| 建筑 | 形制 | 说明 |
| --- | --- | --- |
| 山门 | 三券门红墙 + 歇山顶 | 位于场地前端，门洞打通整堵墙，可透过中门看到院内 |
| 钟楼 / 鼓楼 | 两层 + 平座栏杆 + 攒尖顶 + 宝顶 | 前院东西对称，内挂钟与鼓 |
| 东西配殿 | 三开间 + 歇山顶（青瓦） | 主殿两侧对称 |
| 主殿 | 重檐庑殿顶（金黄琉璃）+ 斗拱 + 菱花隔扇 | 体量最大，位于中轴核心，含三层台基与月台踏跺 |
| 宝塔 | 五层楼阁式 + 逐层收分出檐 + 塔刹 | 后院中轴收尾，全场最高 |
| 廊庑 | 柱列 + 硬山顶 | 东西两侧围合院落 |
| 院墙 | 红墙 + 青瓦压顶 | 留山门与两处角门 |

环境细节：方砖庭院与甬道、路缘石与御路、草地斑块、石狮、铜鼎香炉、灯笼（黄昏点亮）、
幡杆、石灯、照壁、放生池与石桥、井、假山、松树与阔叶树。

## 交互

- 拖拽旋转、滚轮缩放、右键平移（OrbitControls，带阻尼）
- 右上角机位按钮：鸟瞰 / 中轴 / 总平面 / 山门 / 主殿 / 庭院 / 后院宝塔
- 右下角时间档：晨 / 午 / 昏，联动太阳角度、色温、雾、曝光与灯笼自发光
- 首屏默认「鸟瞰」机位，距离由建筑群包围盒反解，保证在任意窗口比例下都完整入画

### URL 参数

- `?view=top`：直接进入指定机位。可选值：`bird`、`axis`、`top`、`gate`、`mainHall`、`courtyard`、`pagoda`
- `?tod=dusk`：直接进入指定时间档。可选值：`dawn`、`noon`、`dusk`

例如 `?view=hall`（不存在时回退到鸟瞰）或 `?view=mainHall&tod=dusk`。

## 技术要点

**体素引擎（`core/voxels.js`）。** 所有几何都写进一个定长 `Uint16Array` 体素网格，
然后做 3D 贪心合并（把同色相邻体素并成最大长方体），最后按材质族分桶实例化。
结果：29 万个体素只产生 19 个 draw call，实心台基、整片铺装、长墙的内部面自动消失。

**中轴对称是结构性保证。** `VoxelWorld.set/box` 每次写入都会连带镜像 `x → -x`，
所以建筑代码只写右半场，左半场由镜像生成；偏轴建筑（配殿、钟鼓楼、廊庑）只写东侧一座，
西侧那一座自动出现。想写出不对称的构件，用 `world.once(fn)` 显式声明。

**越界即报错。** 任何写出世界范围的写入都会抛异常并显示在加载遮罩上，
不会出现「场景里少了东西但没人知道」的隐性故障。

**屋顶是参数化构件。** `buildRoof` 用逐层内收造坡、上段内收加倍做出举折（凹曲线），
檐口四角沿两条边逐格抬升、角部三角出挑做出飞檐翘角，并自动补上垂脊、瓦垄、滴水与脊饰。
`type` 支持 `wudian` / `xieshan` / `cuanjian` / `yingshan` 四种形制。

**光照。** 平行光（4096 阴影贴图 + `normalBias`）+ 半球光 + 环境光，
天穹是渐变球面着色器（带太阳辉光），与雾色、曝光一起随时间档联动。

**构建分阶段。** 场景按 8 个阶段在 `requestAnimationFrame` 切片里生成，
加载遮罩显示当前进度；任一阶段失败都会把错误显示在遮罩上而不是白屏。

## 性能

页面右上角实时显示体素数、合并盒数、draw call、三角面与 FPS。
实测（1440×900）：29.0 万体素 → 1.2 万个合并盒 → 9 个材质族实例，
运行时 19 个 draw call、29.6 万三角面（含阴影贴图通道与天穹）。
实例化之后 draw call 数只取决于材质族数量，与体素数无关。

## 浏览器要求

需要支持 WebGL2（或 WebGL1）的现代浏览器。若上下文不可用或丢失，
加载遮罩会给出明确提示，不会静默失败。

## 调试面

`window.__voxelScene` 暴露最小调试接口，方便人工或自动化检查：

```js
__voxelScene.stats          // { voxels, boxes, families, instances, triangles }
__voxelScene.renderInfo     // renderer.info.render
__voxelScene.view           // 当前机位
__voxelScene.timeOfDay      // 当前时间档
__voxelScene.camera         // { position, aspect, fov }
__voxelScene.setView("top")
__voxelScene.setTimeOfDay("dusk")
```
