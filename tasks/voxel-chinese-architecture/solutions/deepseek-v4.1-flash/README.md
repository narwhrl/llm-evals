# 体素中式院落 · Voxel Chinese Temple Compound

## 运行方式

```bash
npm install
npm run dev      # 本地开发，默认 http://localhost:5173
npm run build    # 生产构建，输出到 dist/
npm run preview  # 预览生产构建
```

打开页面即进入场景，无需任何操作。拖动旋转视角，滚轮缩放（视角被限制在场景上方，避免钻入地面）。

## 结构

| 文件 | 作用 |
| --- | --- |
| `src/voxel.js` | 体素调色板、`Batch` 累积器（按颜色合并为 `InstancedMesh`）、统一材质 |
| `src/parts.js` | 屋面生成器：庑殿/歇山逐层收进、攒尖顶、檐口滴水、斗拱、立柱、木格窗 |
| `src/buildings.js` | 主殿（重檐庑殿）、东西配殿（歇山）、山门、钟楼与鼓楼（攒尖）、七级宝塔 |
| `src/site.js` | 地面铺装与草色、中轴御道、庭院方砖、围墙与角楼、石狮、香炉、松树、水池 |
| `src/main.js` | 渲染器、相机、轨道控制、黄昏光照与阴影、灯笼实例与暖光 |

场景约 4.7 万个体素，按颜色合并为 100 余次绘制调用。所有几何体都是边长 1 的立方体，没有外部贴图或模型资源。

## 布局

中轴自南向北：山门（前）→ 御道与方砖庭院 → 主殿（重檐庑殿，台基最高）→ 塔院与七级宝塔。东西配殿对称分布在主殿两翼，钟楼、鼓楼位于庭院东西两侧，围墙四角各有一座角楼。
