# 栖云古院 · 方寸山河

一个可直接构建运行的 Three.js 中国古典建筑群。六座建筑由程序化体素构成：重檐主殿「栖云殿」、对称配殿「听松堂」「观澜堂」、前端山门以及两座三层宝塔。场景为原创意境设计，并非具体历史建筑的测绘复原。

## 安装与启动

需要 **Node.js 22.12 或更新版本**、npm，以及支持 **WebGL 2** 的现代浏览器。

在本项目目录执行：

```bash
npm ci
npm run dev
```

打开终端显示的本地地址，默认是 `http://127.0.0.1:5173/`。页面加载后直接显示整个院落，无需点击进入。开发服务默认仅监听本机；远程无头服务器可使用 SSH 端口转发后，在自己的电脑浏览器访问。

### 生产构建

```bash
npm run build
npm run preview -- --port 4173 --strictPort
```

访问 `http://127.0.0.1:4173/`。静态构建产物位于 `dist/`，可部署在静态网站服务器或子目录下，不需要后端、API 密钥或外部素材服务。请通过 HTTP 服务访问，不要直接双击 `index.html` 使用 `file://` 打开。

**使用完开发或预览服务后，按 `Ctrl+C` 停止。项目不会自动注册或保留后台服务。**

## 观察方式

- 鼠标左键拖动：旋转；滚轮：缩放；右键拖动：平移。
- 触屏：单指旋转，双指缩放和平移。
- 底部「鸟瞰 / 中轴 / 俯视」：切换预设观察视角，同时恢复全景缩放。
- 加减按钮：缩放；复位按钮：恢复初始鸟瞰全景。
- 顶部「切换暮色 / 切换晨光」：切换光源颜色、方向和环境亮度。
- 键盘：Tab 聚焦画布后，方向键旋转，Shift + 方向键平移，`+` / `-` 缩放，`R` 恢复初始视角；所有界面按钮均可通过 Tab 与 Enter / Space 操作。

## 场景细节

- 中轴石径贯通山门、荷池前院、庭院与主殿台阶。配殿相向布置，双塔位于后方两侧。
- 独立瓦块构成曲面阶梯式庑殿屋顶与攒尖塔顶，包含飞檐翘角、金色屋脊和鸱吻轮廓。
- 朱红立柱、分层斗拱、梁枋、门钉、格栅窗、匾额、灯笼、白石栏杆、台阶与石狮。
- 分层岛台、围墙、草地、松树、叠石、荷池、石灯与庭院香炉。
- 正交相机根据实际几何包围盒及画布比例取景，默认完整展示场地；可自由放大查看细节。

## 实现与性能取舍

原生 JavaScript + Three.js + Vite，无 React、模型下载、图片纹理下载或在线字体依赖。文字匾额由 Canvas 在本地生成，其余建筑与环境主体均由方块构建。

最终场景包含 **17,133 个实例化体素，按 22 种材质合批**；共享立方体几何，避免每个方块一个 Mesh。静止时不持续渲染，仅在交互、缩放、尺寸变化或光照切换时请求绘制；阴影图仅在需要时更新。像素倍率上限为 1.5，使用单盏投影方向光及半球环境光，无后处理链。

```text
index.html                 展示页面与观察控件
src/main.js                WebGL 渲染、光照、交互与资源释放
src/voxels.js              材质与实例化方块构建
src/architecture.js        主殿、配殿、山门、塔楼及构件
src/environment.js         地形、庭院、道路与园林
src/world.js               组合建筑及环境
src/framing.js             自适应全景取景
src/style.css              响应式展示界面
scripts/check-scene.mjs    不依赖浏览器的几何与取景检查
```

## 轻量验证

```bash
node scripts/check-scene.mjs
npm run build
npm audit --audit-level=high
```

几何检查实际运行 Three.js 场景构建，校验六座建筑的主次与对称关系、方块变换的有限性和非退化性、铺装无共面重叠，以及三个视角在四种画布比例下的完整取景。它不替代 WebGL 渲染或视觉验收。

实际执行的构建、无头 WebGL 运行检查、已知限制及进程回收情况见 [RESULTS.md](./RESULTS.md)。
