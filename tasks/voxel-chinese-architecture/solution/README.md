# 体素中国古典建筑群（Voxel Chinese Architecture）

用 Three.js 实现的 Minecraft 风格体素中国古典建筑群场景。纯前端、无后端、无外部资源文件，浏览器打开即进入全貌视角。

## 场景内容

- 中轴对称院落：山门 → 庭院（十字道路）→ 主殿，后轴设五层宝塔
- 建筑 7 座：
  - **主殿**（中轴核心，体量最大）：两层台基、红柱红墙、七开间门窗、斗拱、庑殿顶（金黄琉璃瓦）
  - **配殿 ×2**（主殿两侧对称）：歇山式分层屋顶（青瓦）、五开间、格扇门窗
  - **山门**（南端入口）：三门洞穿行式、匾额、石狮
  - **钟楼 / 鼓楼 ×2**（山门内两翼）：双层檐塔楼，内置铜钟 / 鼓
  - **五层宝塔**（主殿后方）：层层出檐、攒尖顶、金色塔刹
- 细节：飞檐翘角、斗拱、立柱、台阶、匾额、灯笼（自发光）、石狮、香炉、月台铺装、水池、树木
- 环境：草地 + 石板道路 + 庭院铺装、围墙一周、方向光阴影 + 天光补光

## 运行方式

要求：Node.js 18+（开发时使用 Node 24）。

```bash
cd tasks/voxel-chinese-architecture/solution
npm install
```

开发模式：

```bash
npm run dev
# 打开终端输出的本地地址（默认 http://localhost:5173）
```

生产构建与本地预览：

```bash
npm run build     # 产物输出到 dist/
npm run preview   # 默认 http://localhost:4173
```

## 操作

- 打开页面即可看到建筑群全貌（缓慢自动环绕，任意交互后停止）
- 鼠标拖拽旋转 · 滚轮缩放 · 右键平移

## 技术说明

- Three.js（`three`）+ Vite，无 React、无后端
- 所有体素按颜色聚合为 `InstancedMesh` 批量渲染，整场仅需十余个 draw call
- 源码结构：
  - `src/voxels.js` — 体素收集器与调色板
  - `src/buildings.js` — 各建筑生成（台基/屋顶/斗拱/门窗等构件）
  - `src/environment.js` — 地面、道路、围墙、景观
  - `src/main.js` — 场景、灯光、相机与渲染循环
