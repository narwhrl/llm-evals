# 3D 体素高山飞瀑穿云景观 (Voxel Mountain & Waterfall)

基于 **React 18 + Vite + Three.js** 构建的高性能自然体素景观。场景规模达 **200×200 体素世界**，包含巍峨雪山主峰、连绵次峰群、高山天池、千尺悬崖飞瀑、梯级跌水、山腰缭绕穿云、山脚大湖平波、冷杉针叶林与落霞孤鹜的晨昏光影。

---

## 🌟 核心特性与技术实现

1. **200×200 体素大世界与自然山体脉络**
   - 采用多八度 Simplex / Perlin 分形布朗运动 (fBm) 与脊状多重分形算法 (Ridged Multifractal Noise)，辅以距离场加权与指数衰减，雕刻出高拔险峻的雪峰主峰 (海拔 Y≈60) 与东、西、北三座起伏次峰。
   - 地貌具有自然垂直带谱分层：深层玄武基岩 → 花岗岩陡峭石壁 → 高山坚冰积雪 → 中海拔草甸灌丛 → 滨水细沙卵石。

2. **气势磅礴的多级悬崖飞瀑水系**
   - **高山天池**：位于主峰与东次峰之间的深山鞍部 (Y≈41)，作为瀑布丰沛水源发源地。
   - **绝壁主瀑**：宽达 7 格体素的悬崖大瀑布，垂直落差达 19 格体素，双层跌水水幕奔涌而下。
   - **中层回旋碧潭**：承接瀑布水势的天然落水缓冲池 (Y≈22)，激荡起大量白色水沫与腾腾水雾。
   - **次级跌瀑群**：东西两侧分流出曲径级联瀑布，沿苔藓岩石层级跌入山脚。
   - **山麓平湖**：山脚浩淼水域 (Y=8)，波光轻漾，点缀浮萍与翠绿睡莲。

3. **3D 穿云效果与动态遮挡 (Cloud Piercing)**
   - 真实 Minecraft 风格三维厚积云层，飘浮于山腰高度 (默认 Y=34)。
   - **高低纵深与穿云遮挡**：高耸的主峰和次峰傲然刺破云层挺拔于九霄之上，山脚湖泊与平缓草坡隐于云底，云层与山体呈现出真实的立体前后遮挡关系。
   - 云团支持实时缓慢平移漂移，并在控制台中可自由调节云层高度 (Y-Level)、厚度、密度与半透明度。

4. **极致性能保障 (60 FPS & 极低 Draw Calls)**
   - **面剔除 (Face Culling)**：仅在体素朝向空气或透明水体时生成暴露面，大幅削减 85% 以上不可见几何面。
   - **顶点环境光遮蔽 (Vertex Ambient Occlusion)**：依据 26 邻域方块遮挡在顶点着色阶段烘焙 4 档软阴影，营造体素独有的角落阴影细节与立体质感。
   - 全场景采用合并缓冲几何体 (BufferGeometry)，全场景三角面仅约 18 万，Draw Call 仅 4-6 次，各种终端均能稳居 60 FPS 流畅满帧。

5. **全方位交互控制与晨昏氛围切换**
   - **四大晨昏预设**：
     - **晨曦破晓 (Dawn)**：暖金斜阳，晨雾弥漫。
     - **晴空正午 (Noon)**：阳光明媚，山明水秀。
     - **暮色晚霞 (Sunset)**：落日熔金，崖壁生辉。
     - **静谧月夜 (Night)**：冷月清辉，林间萤火飞舞。
   - **开箱全景机位**：页面加载即完整展现 200×200 体素世界全貌，无需手动调节即可尽收眼底。
   - **经典运镜平滑切换**：全貌宏观、飞瀑流泉、主峰穿云、山麓平湖、垂直沙盘一键平滑飞行切换。
   - **实时地形演算**：支持随机种子生成、主峰高度缩放、地形险峻度调节与植被密度重算。

## 🚀 安装与启动方式

### 1. 安装依赖
在 tasks/voxel-waterfall/solution/ 目录下运行：
```bash
npm ci --no-audit --no-fund
```


### 2. 本地开发运行 (手动启动)

```bash
npm run dev
```
启动后在浏览器中打开控制台输出的地址（如 http://localhost:5173）即可观赏。

### 3. 构建生产版本

```bash
npm run build
```
构建产物将输出至 dist/ 目录。

可在本地直接预览生产构建版本。
```bash
npm run preview
```

## 🎮 操作指南

- **鼠标左键拖拽**：旋转视角 (Orbit)
- **鼠标滚轮滑动**：推进 / 拉远视角距离 (Zoom)
- **鼠标右键拖拽**：平移视角中心 (Pan)
- **右上角面板**：可随时展开/收起控制台，调节光影、水流、穿云、相机机位与重构种子。
