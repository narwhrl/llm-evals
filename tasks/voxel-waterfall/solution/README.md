# 云岭瀑境

React、Vite 与 Three.js 实现的 3D 体素自然景观。场景包含 128×128 地形、主峰和次峰、两道沿山势下落的瀑布、山腰体素云层、薄雾与山脚植被。

## 运行环境

- Node.js 20.19+ 或 22.12+
- 支持 WebGL 2 的现代浏览器

## 安装与启动

```bash
cd tasks/voxel-waterfall/solution
npm install
npm run dev
```

终端会输出本地访问地址，默认是 `http://localhost:5173`。页面打开后会自动展示全景并缓慢环绕。

## 构建

```bash
npm run build
npm run preview
```

生产文件生成到 `dist/`。`npm run preview` 只用于本地检查构建结果。

## 验证

```bash
npm test
npm run build
```

## 场景控制

选择右上角“调节景观”，可以实时调整：

- 破晓、晴昼、暮色三组光照
- 云层密度和山腰高度
- 山脚植被密度
- 瀑布显示与流速
- 山谷薄雾
- 镜头自动环绕与环绕速度
- 观景位置重置

鼠标拖动可环绕，滚轮可缩放；聚焦场景后也可使用方向键。

## 性能设计

- 地形数据固定为 128×128，共 16,384 个采样单元。
- 只生成能被看见的体素表面，省去山体内部不可见面。
- 地形、云层、植被和水流均合并或使用 `InstancedMesh`，常规画面约 9 个 draw calls。
- 渲染器根据实测帧率自动调节内部像素比；极弱图形设备会切换到保持原始 128×128 数据范围的低复杂度显示层。
- 页面卸载时会回收 Three.js 几何体、材质、控制器和渲染器资源。
