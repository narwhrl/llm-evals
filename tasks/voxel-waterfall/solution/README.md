# 体素山水 · Voxel Waterfall

Three.js 体素（Voxel）风格自然景观：**山岳 + 瀑布 + 穿云**，Minecraft 式方块拼接质感，React + Vite 工程化交付。

打开页面即是完整全景（主峰、次峰、东南崖壁上的主瀑布、山腰方块云层、山脚植被与晨昏光照），无需任何操作；拖拽旋转、滚轮缩放，右侧面板实时调参。

## 运行方式

```bash
npm install     # 安装依赖（react / react-dom / three + 构建工具链）
npm run dev     # 开发服务器，浏览器打开提示的地址（默认 http://localhost:5173）
```

生产构建与本地预览：

```bash
npm run build     # 类型检查（tsc --noEmit）+ vite build，产物在 dist/
npm run preview   # 本地静态服务预览生产构建
```

## 场景构成

- **山体**：160×160 体素高度场（满足 ≥128×128），域扭曲 ridged 分形噪声 × 高斯山体掩膜生成主峰与 4 座次峰，自然峰谷起伏；按高度/坡度分配草地、岩壁、深岩层理、雪帽配色。
- **瀑布**：主峰东南扇区做径向台地化形成陡崖，确定性算法（崖口扫描 → 泉眼回退 → 蜿蜒引水 → 阶梯刻蚀）把水引到崖口倾泻：着色器流动水幕 + 跌水体素柱 + 瀑潭（浪花）+ 出水溪；另有两道次峰级联跌水。
- **穿云**：山腰高度（可调 14–46）的方块云层，粗噪声生成、行程合并为实例化薄板，逐实例模回绕实现无限漂移；主峰（约 71 格）穿出云层，云层与山体有真实的前后遮挡（深度测试）。
- **环境**：山脚缓坡散布体素树（约 117 棵）、岩石与野花；晨→午→昏时间轴联动太阳方位/高度、天穹渐变、光色、雾色；瀑底水雾 sprite 缓缓升腾。

## 性能设计

- 地形贪心合并网格（颜色入合并键）：约 7 万外壳体素 → 约 12 万四边形（24 万三角形），**单 draw call**；
- 植被/云层全部 `InstancedMesh` + 逐实例颜色；水面独立半透明网格；
- 全场景稳定在 ~20 draw calls / ~30 万三角形（含阴影 pass），任何独显/核显可轻松 60fps；
- `scripts/analyze-shot.cjs` 为验收辅助脚本（PNG 截图像素统计，`node scripts/analyze-shot.cjs <png>`）。

## 调参面板

| 分区 | 参数 |
| --- | --- |
| 地形 | 种子（随机）、山体高度、地形细节、雪线高度、植被密度 —— 触发整体重建（~0.8s） |
| 瀑布与水 | 瀑布流速、瀑布宽度（1/3/5 格）、水体透明度 |
| 云与雾 | 云量、云层高度、云漂移速度、雾浓度 |
| 光照与大气 | 时间（清晨/上午/正午/午后/黄昏）、投射阴影 |
| 视角 | 自动环绕、环绕速度、重置视角 |

滑杆为防抖提交（停顿 160ms 生效），重建型参数拖动流畅。
