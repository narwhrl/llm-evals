# 体素瀑布 · Voxel Waterfall

Three.js 体素（Minecraft 风格）自然景观场景：主峰与次峰组成的山脉、沿山势而下的多级瀑布、
山腰穿云的云海、山脚森林与湖面涟漪，默认黄昏光照，可一键切换黎明 / 正午 / 夜晚。

基于 **React 18 + Vite 5 + Three.js 0.170**。场景为 208×208 体素世界，打开页面即自动进入
默认机位并开始缓慢环绕，无需任何操作即可看到全貌。

## 运行方式

```bash
npm install     # 安装依赖
npm run dev     # 开发模式，默认 http://localhost:5173
```

生产构建与预览：

```bash
npm run build   # 产物输出到 dist/
npm run preview # 本地预览 dist/，默认 http://localhost:4173
```

## 可调选项（右上角设置面板）

| 分组 | 选项 |
| --- | --- |
| 光照时段 | 黎明 / 正午 / 黄昏 / 夜晚（平滑过渡，夜晚含星空） |
| 云海 | 云层高度（20–46）、云量（0–100%） |
| 瀑布与河流 | 瀑布数量（1/2/3 道，重建水系）、水流速度（0.2x–3x） |
| 植被 | 树木密度（0–100%） |
| 视角与画质 | 自动环绕开关、阴影开关、重新生成地形（随机种子）、重置视角 |

相机：左键拖动旋转、滚轮缩放、右键平移；手动操作会自动暂停环绕。

## 代码结构

```
src/
  main.jsx              入口
  App.jsx               设置面板（React）
  styles.css            面板样式
  scene/
    createScene.js      场景组装、重建管线、动画循环、选项 API
    terrain.js          高度场生成、瀑布河道追踪与开挖、实例化体素网格
    water.js            阶梯状水带与湖面着色器、跌水浪花粒子
    clouds.js           云海簇团与贴山水雾
    vegetation.js       森林与岩石（实例化）
    environment.js      天空穹顶着色器、光照与时段预设
    noise.js            值噪声 / fBm / ridged 噪声
```

## 实现说明

- **山体**：主峰 + 3 座次峰的质量域叠加，ridged 峰谷细节集中在山腰，主峰带两道环形阶地
  陡崖、次峰各带一道小陡崖，瀑布从崖顶跌落；雪线以上覆雪，陡壁露岩。
- **瀑布**：从各峰顶附近最高点做贪心下坡追踪河道，遇闭合洼地涨水溢出垭口；河道开挖后两侧
  自动筑岸，终点挖湖。水带为逐格水平面 + 落差处竖直立面，着色器沿流向滚动泡沫条纹；
  每个跌水点喷发抛物线浪花粒子，大跌水处附加贴山水雾。
- **穿云**：云海由 34 团多盒体簇组成，七成环抱山腰、三成散布外围，默认高度位于山腰
  （32），主峰（高约 61）穿出云层；云与山体、云与云之间有前后遮挡。
- **性能**：地形 / 树木 / 岩石 / 浪花全部实例化渲染，默认机位约 54k 体素实例、60 FPS（1080p）。
