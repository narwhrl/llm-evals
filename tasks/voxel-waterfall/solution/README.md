# Voxel Waterfall · 体素瀑布场景

Three.js + React + Vite 实现的 3D 体素自然景观：体素山脉（主峰 + 次峰）、
从山体高处顺坡而下直至山脚的瀑布、缠绕山腰的体素云层（峰顶穿出云层）、
山脚体素树林，以及可调节的晨昏光影。打开页面即见全貌，无需任何操作。

## 运行方式

```bash
cd tasks/voxel-waterfall/solution
npm install
npm run dev      # 开发服务器，默认 http://127.0.0.1:5173
```

生产构建：

```bash
npm run build    # 产物输出到 dist/
npm run preview  # 本地预览构建产物
```

## 操作

- 拖拽旋转视角，滚轮缩放，右键平移
- 右侧面板实时调整选项（改动即时生效）：
  - **地形**：随机种子、网格尺寸（200×200 ~ 260×260）
  - **瀑布**：瀑布道数（1–3）、水流宽度（1–3）
  - **云层**：云带高度、云量
  - **环境**：晨昏时间、雾气浓度、植被密度、自动环绕
  - 「随机生成新地形」按钮一键换 seed

## 实现要点

- 山体为确定性分形/脊状噪声高度图，只渲染表面壳层体素（顶面 + 露出的侧壁），
  全部打包进单个 `InstancedMesh`（约 4.9 万实例，含侧壁约 10 万体素总量）。
- 瀑布由高处泉眼沿最低邻域严格下降自动寻路；遇洼地会切穿洼口形成跌水，
  水帘沿落差逐格填充，末端在山脚散布泡沫块。水体为独立 InstancedMesh，
  片元着色器注入时间 uniform 做流动闪烁动画，瀑布/泡沫带自发光保证背光面可读。
- 云层为山腰高度带内的椭球体素团簇（噪声侵蚀出蓬松边缘），与山体之间
  依赖深度缓冲正确互相遮挡，部分次峰高于云带穿出云层。
- 山脚按坡度散布体素树（树干 + 树冠），海平面以下填充水体体素，
  网格外延一块同色海面平面衔接至雾中。
- 方向光（随晨昏移动）+ 半球光 + 渐变天空穹顶 + 线性雾，ACES 色调映射。
- 相机初始机位自动朝向瀑布所在正面，加载即见全貌。
