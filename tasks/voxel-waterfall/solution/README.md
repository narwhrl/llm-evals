# 体素山水 · Voxel Waterfall

一个基于 **React + Vite + Three.js** 的 3D 体素风格自然景观：体素山脉（主峰 + 次峰）、
从高处倾泻而下的瀑布与山脚水潭、缭绕山腰并让峰顶穿出的体素云层、山脚植被，
以及晨昏可调的光影氛围。打开页面即呈现全貌并自动缓慢环绕，无需任何操作。

## 运行方式

```bash
cd tasks/voxel-waterfall/solution
npm install       # 安装依赖（Node >= 18）
npm run dev       # 开发服务器，默认 http://localhost:5173
```

生产构建与预览：

```bash
npm run build     # 产物输出到 dist/
npm run preview   # 本地预览生产构建
```

## 场景要素

| 要素 | 实现 |
| --- | --- |
| 山体 | 160×160 体素高度场；高斯峰包络（1 主峰 + 3 次峰）× 山脊噪声，峰谷起伏自然 |
| 瀑布 | 泉眼起自主峰侧翼，沿平滑地形最速下降寻路；河道下切，最陡处放大为陡崖形成高大水幕，山脚冲蚀出水潭 |
| 穿云 | 两层体素云带环绕山腰（x 向周期化噪声，漂移回绕无缝），主峰穿出云层，前后遮挡由深度测试保证 |
| 植被 | 山脚草甸散布体素树（树干 + 分层树冠），避开河道与陡坡 |
| 光影 | 晨→午→昏时辰插值：渐变天穹、太阳平行光（体素 AO + 阴影）、半球光、雾 |

## 可调选项（右侧面板）

- **地形**：山体高度、起伏细节、雪线、🎲 随机种子重新生成
- **瀑布**：显示开关、流速、主落差、河道宽度
- **云层**：覆盖率、云层高度、漂移速度、通透度
- **光照·植被**：时辰（清晨/正午/黄昏）、树木数量
- **视角**：自动环绕开关、重置视角

参数变更按需局部重建（地形/云/树）或实时生效（流速、光照、透明度），
重建有 90ms 防抖，拖动滑杆流畅。

## 性能

- 地形为消隐面（culled-face）合并网格：约 5.7 万四边形、全场景个位数 draw call；
  体素规模 160×160（任务要求 ≥128×128）。
- 世界整体重建（换种子）耗时约 0.26s（Node 22 实测）。
- 页面内置 FPS HUD；在常规 GPU 上可稳定 60fps。
  无 GPU 的纯软件渲染环境（如无显卡虚拟机）会显著降速，属环境限制。

## 操作

拖拽旋转 · 滚轮缩放 · 右键平移；页面打开即自动环绕展示。

## 结构

```
src/
├── main.jsx / App.jsx / index.css   # React 外壳与 HUD
├── options.js                       # 默认参数
├── ui/ControlPanel.jsx              # 控制面板
└── scene/
    ├── noise.js        # 种子化值噪声 / fBm / 山脊噪声 / 周期噪声
    ├── terrain.js      # 高度场生成 + 生物群系配色
    ├── builder.js      # 可增长的几何缓冲构建器
    ├── mesher.js       # 地形/水体消隐面网格（顶点色 + AO）
    ├── water.js        # 河道寻路、下切、水潭 + 水体着色器
    ├── clouds.js       # 周期化体素云带（漂移无缝回绕）
    ├── vegetation.js   # 体素树
    ├── sky.js          # 天穹 / 光照 / 雾（时辰驱动）
    └── VoxelScene.js   # 场景编排、渲染循环、参数应用与释放
```
