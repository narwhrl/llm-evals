# Voxel Waterfall — 体素山水

一个可在浏览器中直接观看的 3D 体素（Voxel）风格自然景观：山脉 + 瀑布 + 穿云效果。
基于 **React + Vite + Three.js**，Minecraft 式方块拼接风格。

## 运行方式

```bash
cd tasks/voxel-waterfall/solution
npm install
npm run dev        # 开发模式，终端会输出本地地址（默认 http://localhost:5173/）
```

生产构建与本地预览：

```bash
npm run build      # 输出到 dist/
npm run preview    # 预览生产构建
```

打开页面即进入场景，无需任何操作即可看到全貌（默认清晨光照 + 缓慢自动旋转）。

## 场景特性

- **山体**：128×128 体素柱高度图。主峰（带 2–3 个肩峰打破对称）+ 4–6 座次峰，
  高斯峰体 max 混合 + fBm 基底起伏 + 海拔噪声粗糙度 + 径向边缘衰减 + 两遍平滑，
  峰谷起伏与坡度过渡自然；按海拔/坡度着色（草地→亚高山带→岩壁→雪线→积雪）。
- **瀑布**：1–3 道（可调）。从最靠近主峰的泉眼沿最陡下降路径流下；生成后在地形上
  凿出单调下降的水道，主瀑布保证两处 4–7 格高的垂直跌水；缓坡段水流自动加宽，
  对角路径自动补正交连接格；山脚凿出积水潭（水潭 + 沙岸 + 上升水雾粒子）；
  水流用实例色相位动画表现向下流动感。
- **穿云**：体素云团沿切线方向连成云带，环绕山腰缓慢漂移；高于云层的峰顶穿出
  云层；云为半透明（depthWrite 关闭 + 正确 renderOrder），与山体前后遮挡关系正确。
- **环境**：山脚点缀体素树木（自动避开水道 2 格）；晨/午/昏三档光影预设
  （太阳方位/颜色/天空/雾/半球光联动），默认清晨暖色调。

## 性能设计

- 所有体素使用 `InstancedMesh`：整场景约 **10 个 draw call**、约 70 万三角形。
- 地形只做**表面体素化**（顶面 + 暴露侧面），不实心填充，128×128 地形约 3 万实例。
- 全部 InstancedMesh 关闭视锥剔除（实例包围盒不适用），单张 2048 阴影贴图。
- 实测：无头软件渲染（SwiftShader）1280×800 下约 60 FPS；真实 GPU 远超 30 FPS 要求。

## 可调选项（右侧面板）

- 光影：时段滑杆（清晨/正午/黄昏连续过渡）+ 三档预设
- 云雾：密度（0–28 团）、高度、漂移速度
- 瀑布：显示开关、数量（1–3）、流速、水雾开关
- 山体：雪线高度、植被密度、随机种子（可输入或一键随机换山）
- 视角：自动旋转开关与速度；拖拽旋转 / 滚轮缩放 / 右键平移
- 面板底部实时显示体素总数与 FPS

## 项目结构

```
solution/
├── index.html
├── package.json
├── vite.config.js
└── src/
    ├── main.jsx
    ├── App.jsx                 # 参数状态与布局
    ├── styles.css
    ├── scene/
    │   ├── VoxelScene.jsx      # Three.js 生命周期、渲染循环、FPS 统计
    │   ├── rng.js              # 种子随机数、值噪声、fBm
    │   ├── heightmap.js        # 128×128 山体高度图生成
    │   ├── terrain.js          # 地形表面体素化 + 着色
    │   ├── waterfall.js        # 流路寻径、水道开凿、水体/水雾网格与动画
    │   ├── clouds.js           # 体素云带
    │   ├── vegetation.js       # 山脚树木
    │   └── lighting.js         # 晨/午/昏光照、天空、雾
    └── ui/
        └── ControlPanel.jsx    # 参数控制面板
```
