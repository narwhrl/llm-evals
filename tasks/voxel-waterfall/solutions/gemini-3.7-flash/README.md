# 3D Voxel Mountain & Waterfall (体素高山瀑布穿云景观)

基于 **Three.js + React + Vite + TypeScript** 构建的高性能 3D 体素（Voxel）风格自然景观场景。呈现包含主峰与次峰起伏的巍峨体素山脉、山腰缭绕与雪峰穿云效果、高山飞流倾泻的动态瀑布水系（自定义流体着色器）、水花飞溅粒子系统与丰富植被生态，并支持全天候晨昏光影与全参数实时调控。

---

## 🌟 场景特色与核心实现

### 1. 巍峨体素山脉 (Procedural Voxel Mountains)
- **超大体素网格**：采用 **144 × 144** 超大地表投影网格（高度达 80 层），远超 128×128 标准。
- **多层级地形生成算法**：结合多八度分形噪声（FBM）、脊状多重分形噪声（Ridged Multi-Fractal Noise）与山峰调制函数，生成兼具巍峨主峰（高达 74 层）与 4 座次峰、险峻山脊、缓坡与深邃峡谷。
- **生态地貌分层材质**：
  - 高峰顶层（y ≥ 55）：终年积雪（Snow）与透亮冰川（Ice）。
  - 陡峭岩壁与山脊：石板灰岩（Stone / Slate）与深色玄武岩（Dark Stone）。
  - 山腰与平缓山坡：高山草甸与苔藓岩石（Mossy Stone）。
  - 峡谷与谷底平原（y = 14 ~ 30）：翠绿草地（Lush Grass）与深层泥土（Dirt）。
  - 湖岸与深水区：细软沙滩（Sand）、砾石（Gravel）与清澈湖泊（Water）。

### 2. 飞流直下汇入碧湖 —— 完整水文循环与瀑布水体系统 (Waterfall & Grand Alpine Lake)
- **完整高山水系拓扑结构**：
  - **雪峰天池冰泉 (Glacial Cirque Tarn, y = 58)**：主峰下方雪水融聚形成高山冰湖源头。
  - **上段峡谷飞瀑 (Upper Cascade Gorge, y = 58 → 38)**：冲刷深 V 峡谷倾泻至山腰。
  - **山腰跌水潭 (Mid-Mountain Plunge Pool, y = 38)**：山腰宽阔阶梯蓄水池，周围点缀苔藓岩与落樱。
  - **悬崖大瀑布直坠入湖 (Grand Waterfall Plunge, y = 38 → 14)**：瀑布自悬崖绝壁垂直轰鸣下泻，形成 4~5 体素宽的立体水帘，直接注入山脚广阔的碧蓝大湖！
  - **次峰支流瀑布 (Eastern Tributary Fall)**：自东峰悬崖奔流汇入大湖北湾。
- **山脚广阔碧蓝大湖 (Grand Alpine Lake)**：
  - 拥有自然分形海岸线（海湾、沙滩与砾石浅滩），湖水深澈（水深达 8 层体素），湖面晶莹透亮。
  - 瀑布冲击点直抵湖面深水区，水流顺畅扩张汇聚于湖盆中央。
- **动态物理激浪与水文交互**：
  - **抛射体素水花 (Cubic Voxel Droplets)**：落水撞击湖面激起弹道抛物线飞溅水珠。
  - **升腾水汽云团 (Rising Mist)**：带浮力与风向对流的柔软水雾缭绕于湖面。
  - **湖面激浪涟漪 (Expanding Wave Ripples)**：落水冲击点持续生成八边形同心涟漪波纹，向广阔湖面扩散衰减。

### 3. 山腰缭绕 · 破云而出 (Volumetric Voxel Clouds & Piercing Effect)
- **山腰体素云毯**：在海拔 y = 36 ~ 44 处动态生成 Minecraft 风格的立体厚实 3D 体素云块。
- **穿云遮挡视觉层次**：雪峰高耸破云而出（主峰露出云层 30+ 体素），山体在云层间若隐若现，形成真实的前后遮挡景深与柔和体积阴影。
- **随风飘逸**：支持云层沿风向平滑漂移与循环卷绕，同时在山谷幽壑中点缀微风游雾。

### 4. 植被生态与微气候氛围系统 (Biomes & Micro-Atmosphere)
- **多样化体素树木**：
  - 高海拔山坡：针叶冷杉/云杉松树（Layered Pine Conifers）。
  - 谷底林地：繁茂绿叶橡树（Oak Trees）与白桦树（Birch Trees）。
  - 瀑布与湖畔：粉色浪漫樱花树（Sakura Trees）。
- **生动氛围粒子系统 (AtmosphereSystem)**：
  - 🌸 **浪漫落樱**：樱花树周围随风轻舞飘落的粉色花瓣粒子。
  - 💡 **自发光萤火虫**：黄昏/月夜/极光下在湖畔草丛中浮游呼吸闪烁的萤火虫群。
  - ❄️ **高山冰晶**：巍峨主峰周围随高空强风呼啸飘散的冰霜微粒。
- **生机点缀**：红花、黄花、蓝花与灌木点缀草地；湖畔建有木质亲水栈道与悬挂灯笼（夜间自发光暖光，带有自然火焰呼吸闪烁效果）。

### 5. 全天候光影与晨昏氛围 (Dynamic Time of Day)
- **大气天穹穹顶 (Atmospheric Sky Dome)**：垂直双色平滑渐变的天空穹顶与日晕光环（Sun Halo）。
- 提供 5 套调色与光影预设：
  - 🌅 **晨曦 (Dawn)**：低角度暖橙朝阳、粉紫渐变天空与清晨薄雾。
  - ☀️ **晴空 (Day)**：明亮正午阳光、清澈碧蓝苍穹与高对比度阴影。
  - 🌇 **晚霞 (Sunset)**：绚烂落日晚霞、金红山体与长投影。
  - 🌙 **月夜 (Night)**：静谧深蓝月光、点点繁星与湖畔栈道暖黄灯笼光晕。
  - 🌌 **极光仙境 (Fantasy Aurora)**：神秘紫绿极光与荧光水流。

### 6. 极速流畅渲染 (≥60 FPS 性能架构)
- **表面体素剔除 + 顶点环境遮挡 (Voxel AO)**：
  - 剔除所有地下不可见内面，面数降低 80% 以上。
  - 为每个体素四边形顶点计算 Minecraft 级别的 3-Neighbor 局部环境光遮挡（AO），产生柔和的角落阴影。
  - 合并为单一缓冲几何体（Merged BufferGeometry），**全场景仅需 2~3 个 Draw Calls**，即使在普通集显/笔记本上也可稳定维持 60 FPS！

## 🛠️ 技术栈

- **前端框架**：React 19 + TypeScript
- **构建工具**：Vite 6
- **3D 图形引擎**：Three.js (WebGL, OrbitControls, PCFSoftShadowMap, Custom ShaderMaterial, Custom Particles)
- **图标与样式**：Lucide-react, Modern Glassmorphism CSS

## 🚀 安装与运行

### 1. 安装依赖
```bash
cd tasks/voxel-waterfall/solution
npm install
```

### 2. 启动开发服务器（本地预览）
```bash
npm run dev
```
启动后在浏览器打开终端提示的地址（通常为 `http://localhost:5173/`）。页面打开即可进入全景视角，自动环绕观赏。

### 3. 构建生产版本
```bash
npm run build
```

### 4. 预览生产构建
```bash
npm run preview
```

## 🎮 操作控制指南

### 鼠标 / 触控交互
- **鼠标左键按住拖拽**：360° 自由旋转视角（Orbit）
- **鼠标右键按住拖拽**：平移视角位置（Pan）
- **滚轮滚动 / 双指捏合**：缩放镜头距离（Zoom）

### 底部快捷镜头
- 🏔️ **全景概貌**：鸟瞰整座高山、瀑布与湖泊全貌
- 🌊 **瀑布特写**：近距离观察峡谷飞瀑与飞溅水花
- ☁️ **穿云绝顶**：仰望穿透云海的巍峨雪峰
- 🛶 **碧湖栈道**：湖畔码头低视角，仰望瀑布与山脉
- 🚁 **环绕巡航**：全自动平滑航拍电影级镜头漫游

### 场景调控抽屉（右上角「参数调控」）
- **时序与光影**：光照强度、环境雾气浓度
- **云层与穿云**：云层海拔高度、云量覆盖密度、风速流动、云层厚度
- **瀑布与水流**：流速、水花粒子数量、水体透明度
- **地形与植被**：植被树木覆盖率、🎲 随机生成新种子地形
- **画面工具**：📷 一键导出高清 PNG 截图、自动旋转开关与速度、全屏切换
