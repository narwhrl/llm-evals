# 体素山景 · Voxel Vista

React + Vite + Three.js 实现的 Minecraft 风格体素自然景观：主峰与次峰、顺坡瀑布、山腰穿云、山脚植被，打开页面即可看到全貌。

## 运行

```bash
cd tasks/voxel-waterfall/solution
npm install
npm run dev
```

浏览器打开终端里提示的本地地址（默认 `http://localhost:5173`）。页面加载后自动进入场景，无需先操作。

生产构建：

```bash
npm run build
npm run preview
```

## 场景

- **山体**：128×128 柱体网格，主峰 + 多座次峰，坡度与峰谷由多层噪声叠加
- **瀑布**：从主峰与侧峰沿最陡路径倾泻，落入山脚水潭
- **穿云**：云层环绕山腰，高峰穿出云海，前后遮挡由深度测试处理
- **环境**：山脚林木、晨昏光影、雾气与天空渐变

右侧面板可调节晨昏、雾气、云层、瀑布流速、山体尺度、植被、种子、自动旋转和阴影。

## 操作

- 拖拽：旋转视角
- 滚轮：缩放
- 右键拖拽：平移
- 默认开启缓慢自动旋转
