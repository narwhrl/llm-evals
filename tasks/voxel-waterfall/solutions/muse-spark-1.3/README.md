# 体素山水 · Voxel Waterfall

Three.js 体素自然景观：主峰 + 次峰山脉、沿山体倾泻的瀑布、山腰穿云、
山脚湖泊植被，晨/午/昏三种光照。浏览器打开即进入场景全貌。

## 运行

```sh
npm install
npm run dev      # 开发：http://localhost:5173
npm run build    # 生产构建 → dist/
npm run preview  # 预览生产构建：http://localhost:4173
```

构建产物 `base` 为相对路径，可部署到任意子路径。

## 操作

- 打开即自动环绕展示全貌；拖拽旋转、滚轮缩放、右键平移。
- 右侧面板可调：地形尺寸（120/160/200）、主峰高度、瀑布数量/宽度/流速、
  云量/云高/漂移速度、植被密度、时段（清晨/正午/黄昏）、自动环绕。

## 实现

- `src/voxel.js`：确定性值噪声高度场（1 主峰 + 3 次峰 + fbm 峰谷起伏 +
  前缘湖盆），每列只保留可见壳体素；瀑布沿最速下降 trace 并加宽，
  水体相位动画模拟下滚；云为山腰扁椭球 voxel 簇整团漂移；树木/草块
  按高度与坡度播撒。
- 地形/树木/草一次 `InstancedMesh` 绘制，瀑布/湖/云各一次，共 5 个
  draw call 级别，200×200 地形下体素总数约 8–12 万。
