【任务】
请做一款能在浏览器里直接玩的第一人称团队枪战，场景尽可能按公开资料还原《穿越火线》团队竞技地图「运输船」。实现必须写在 `tasks/cf-transport-ship/solution/`。不要把实现写到其他路径，也不要修改本任务的 `task.md`、`README.md` 或仓库其余共享输入。

这是一局能打完的枪战，不是静物沙盘，也不是只能走不能打的演示。页面打开后，玩家以第一人称登上货轮船面，与会射击、会换弹、会走路线的对手争夺击杀。

【地图：运输船】

地形窄、纵深长，甲板在海面之上。双方出生在两端舱室：保卫者在船头舱，潜伏者在船尾舱。船头尖端和船尾末端只作为船体造型，不能走进去。

公开打法里这张图有五条路，中间三条相通：

1. **中路（大口）**  
   从保卫者出生舱大门能直接看到潜伏者出生舱大门。这是狙击手的长视线，眼高处的弹道不能被集装箱、舱壁或船体挡住。中路是全图最危险的对枪缝。

2. **两条小道**  
   紧贴中路两侧，并有缺口能切进中路。每条小道里至少有一只**木箱**挡住直视，步枪子弹可以穿过这只木箱并仍造成明显伤害；铁箱、集装箱和舱壁挡子弹。小道是突击兵对撞的路，过箱前可以穿箱预瞄。

3. **两条舷侧通道（管道 / 右通道）**  
   各方出生点靠自己的右侧都有一条通道，只能从出生舱小门附近进入，用来绕到敌方半场。通道尽头是可以跳上或走上去的高处，从那里能俯瞰甲板大部；敌方出生舱内部仍应被舱壁挡住，不能从这条高处直接清掉复活点深处。高处可以跳回甲板。

地图大体镜像，但不要做成完美对称。至少要能看出这些公开点位差异：

- 一方出生舱多出一间小舱室或向外凸出的结构。
- **斜箱**：小道上有斜放的集装箱或箱子，留出可挤过的缝，形成拐弯盲区。
- **八字绿箱**：中场有一对绿色集装箱呈「八」字，朝潜伏者一侧开口更宽，但不得切断中路眼高视线。
- **三箱**：保卫者侧有一组需要连跳才能上去的箱子，能继续跳上旁边的集装箱顶。
- **高箱**：中路附近有可站立的集装箱顶。潜伏者一侧的高箱上另有一只可穿透木箱；保卫者一侧的对应高箱更暴露。
- **地下道**：甲板下有一条能走通的低舱，两端有下舱口和台阶。地下道上方的甲板附近有一只木箱，可作掩体，这只木箱可被步枪打穿。
- **左路出口铁箱**：靠近保卫者小道出口有不可穿透的铁箱，适合架枪看向敌方中路出口。

甲板上要有成组的红、蓝、橙、绿色集装箱、木箱、铁箱、油桶、栏杆、吊机或桅杆、舱室窗和门外的待命区。船体外观要能认出是一艘在航行的货轮：船壳、吃水线、船首、船尾、海面和天空都要在。材质用程序纹理或本地资源，呈现旧漆、锈蚀、防滑甲板和木板，不要整图灰盒。

【枪战】

- 第一人称，鼠标控制视角，指针锁定。WASD 移动，Shift 静步，Ctrl 或 C 蹲下，Space 跳跃。跳跃能上木箱和规定的高箱，不能一步跳上普通集装箱顶。
- 碰撞要挡住人：墙、箱、栏杆、舱壁都走不过去；台阶和斜坡高处要走得上去；从舱口可以下到地下道再从另一端上来。
- 武器至少包括：近战刀、手枪、一把偏高后坐的步枪、一把更稳的卡宾枪、冲锋枪、栓动狙击。狙击开镜后视野明显变窄、散布极小，腰射很散。数字键或滚轮切换。R 换弹。弹匣打空要换弹，备弹打空不能继续射击。
- 命中要分头和身体。头部伤害更高。步枪大约三四发身体击倒一名满血目标，狙击在有效距离内身体一发击倒。移动、连射会让散布和后坐变大，停下来点射更准。
- **穿箱**是这张图的核心：步枪和狙击能打穿木箱，伤害下降但仍然致命；冲锋枪和手枪要么穿不过，要么穿过去只剩擦伤。铁箱、集装箱、舱壁挡住子弹。
- 高爆手雷和烟雾弹。手雷有飞行时间、爆炸范围和衰减；烟雾要挡住视线（玩家和对手都看不见烟里的目标）。闪光弹不要做。
- 生命值、护甲、受击方向、击中反馈、击倒提示。被击倒后数秒在本方出生舱复活，复活时补满弹药和投掷物。出生后有很短的保护，开火或离开舱室后保护结束。
- 模式是团队竞技：保卫者对潜伏者，先达到击杀上限或时间结束时击杀更多的一方获胜。默认 5 对 5，玩家占其中一个名额，其余为电脑。电脑必须真正参与枪战：沿中路、小道、管道或地下道移动，看见敌人会开枪、会换弹、会利用木箱和掩体，不能站桩挨打，也不能透视全图。
- 队友误伤关闭。队友要能认出来（颜色或名字）。

【界面与呈现】

- 准星、弹药、生命、护甲、双方比分、击杀信息、小地图。小地图要能分辨中路、小道、管道和双方舱室，并标出队友；敌人开火时可以短暂暴露位置。
- 武器要有能认出种类的第一人称模型，以及枪口焰、弹道或弹痕中的至少两类反馈。对手是可辨认的人体轮廓，不是悬浮的盒子。
- 海面要有起伏。光照要能看清掩体和舱内，舱内比甲板暗。阴影能帮人判断箱子的体积。
- 声音用程序合成或本地资源：枪械、换弹、脚步、爆炸、海浪。没有资源时也要有可辨别的枪械声和受击声。
- 暂停、重新开始、灵敏度记忆。桌面 1440×900 下必须能完整打一局。触屏可以降级，但不能在桌面端把鼠标视角弄坏。
- 文案使用中文。不要使用官方游戏的商标、Logo、角色模型、贴图、音效或解包资源。武器用描述性名称，不要用受保护的商业型号名。
