# 运输船

浏览器里的第一人称团队枪战。场景按公开打法资料重建货轮甲板：船头舱是保卫者，船尾舱是潜伏者。没有使用官方贴图、模型、音效或商标。

## 安装

```bash
npm install
```

## 本地运行

```bash
npm run dev
```

然后打开终端里给出的本地地址。桌面分辨率 1440×900 可以完整打完一局。

## 生产构建

构建命令接受 Vite 的 `--base` 和 `--outDir`：

```bash
npm run build -- --base=/cf-transport-ship/grok-4.7/ --outDir=dist
```

## 测试

```bash
npm test
```

## 操作

- WASD 移动，Shift 静步，Ctrl 或 C 蹲下，Space 跳跃
- 鼠标控制视角，左键射击，右键瞄准，R 换弹，滚轮切换匕首 / 手枪 / 主武器
- 1 匕首，2 手枪，3 主武器，4 或 G 高爆手雷，5 或 X 烟雾弹
- B 或 Esc 暂停并更换主武器，Tab 计分板，点击顶部比分也可以打开计分板
- 主武器可选 47式步枪、卡宾枪、冲锋枪、栓动狙击
- 步枪和狙击可以打穿木箱，冲锋枪和手枪会被木箱挡住
- 先到 30 击杀，或 6 分钟后击杀更多的一方获胜

灵敏度保存在本机 `cf-ship-sens`。
