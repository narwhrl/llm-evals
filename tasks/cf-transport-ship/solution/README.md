# 运输船 · 浏览器第一人称团队竞技

以《穿越火线》端游经典团队竞技地图「运输船」为空间参照的本地 5 对 5 第一人称枪战（1 名玩家 + 9 名电脑）。Three.js + Vite + TypeScript，所有模型、贴图、音效均在运行时程序生成，无外部运行时资源。

## 环境要求

- Node.js 20 及以上（实测 v24.21.0，npm 11.19.0）
- 支持 WebGL2 与 Pointer Lock 的桌面浏览器（实测 Chrome 153，Windows）
- 键盘与鼠标

## 命令

在本目录执行：

```bash
npm ci                 # 按锁文件安装依赖
npm run dev            # 开发服务器，终端会打印本地地址（默认 http://localhost:5173/）
npm run typecheck      # tsc --noEmit
npm test               # vitest run，逻辑测试
npm run build          # 类型检查 + 生产构建到 dist/
npm run preview        # 以静态服务预览 dist/

# 子路径部署：base 与 outDir 均可通过命令行指定
npx vite build --base /games/cf-transport-ship/ --outDir dist-subpath
npx vite preview --base /games/cf-transport-ship/ --outDir dist-subpath
```

在 Git Bash（Windows）中传入以 `/` 开头的 `--base` 时，需要加 `MSYS_NO_PATHCONV=1`，否则路径会被改写成 Git 安装目录。

生产包（`dist/`）是纯静态文件，可用任意静态服务器托管。必须通过 HTTP 打开，直接双击 `index.html` 不受支持。

## 对局

- 标准：先到 100 击杀或 10 分钟，时间到按比分决胜，同分为平局。练习局：30 击杀 / 3 分钟。
- 死亡 3 秒后在本方船舱复活；出生保护 2 秒，开火或离开出生区域即结束。
- 关闭队友伤害；友军会挡子弹但不受伤。
- 难度（简单 / 普通 / 困难）只调节电脑的反应、瞄准误差、转向速度和协同频率，所有难度共享同一套规则。

## 调试入口

在地址后加 `?debug` 会挂载 `window.__cf`（状态快照、传送、固定机位、静止靶、冻结电脑、快进模拟），并显示电脑路线与状态。`&seed=N` 可固定随机种子，`&nolock` 可跳过指针锁定（仅供自动化，HUD 会注明）。生产默认界面不挂载这些功能。

## 常见问题

- **点击「开始游戏」后没有锁定鼠标：** 浏览器在刚退出锁定后约 1 秒内会拒绝再次锁定。页面会显示提示，稍候再点即可。
- **没有声音：** 音频在第一次点击后才初始化，属于浏览器的播放限制。请检查总音量与音效音量设置。
- **提示 WebGL 不可用：** 请开启浏览器硬件加速，或换用支持 WebGL2 的浏览器。
- **子路径部署后资源 404：** 构建时的 `--base` 必须与实际托管路径一致，且以 `/` 结尾。

## 目录

- `src/`：源码，按模块划分为 `core`（碰撞/空间查询）、`map`（地图数据）、`combat`、`ai`、`game`（对局/输入/循环）、`render`、`audio`、`ui`
- `tests/`：Vitest 逻辑测试
- `docs/`：`MAP_REFERENCE.md`、`ASSET_CREDITS.md`、`ACCEPTANCE.md`
- `references/`：地图参考截图（仅用于分析，不进入构建）
- `evidence/`：实机截图与测量日志
