# 运输船 地图参照与重建依据

## 1. 版本选择

**选定参照版本：端游《穿越火线》经典「运输船」（2008 前后经典版本布局，即社区通称的"经典运输船"）。**
全部空间关系以同一时期的俯视图与实机截图为基准；手游运输船 / 手游 HD / CFHD / 其他游戏的集装箱地图不作为布局依据。CF2.0 画面资料（R10）仅用于海天、吊机等环境氛围观察，未参与布局定版。

参照资料全部来自任务给定的 R04–R09 链接（3DMGame 攻略页及其图床），已保存至 `references/`，来源与校验值见 `references/manifest.md`。视频走图资料在实施环境不可用（见 §6），连续路线关系以俯视图 + 实机截图 + 任务描述交叉核对。

## 2. 坐标系与尺度

- 坐标系：**X 沿船长**（+X 船首=蓝方保卫者，−X 船尾=红方潜伏者），**Z 舷侧**（+Z 右舷），**Y 向上**，甲板面 **y=0**。
- 比例尺校准基准：人物站高 1.82 m、眼高 1.62 m；门高约 2.7–3.0 m；标准集装箱 6.06×2.44×2.59 m（国际通用规格，图中箱体与人高比例相符）；木箱约 1.1 m（及腰）。
- **甲板可玩区长约 104 m（x∈[−52,52]），宽约 30 m（z∈[−15,15]）**。此为**估计值**：按俯视图中人物/箱体相对比例推算（R05 为小分辨率俯视图，边缘模糊，读数误差约 ±10%），非官方数据。
- 端部舱体进深约 12 m（x∈[52,64]），宽 14 m，高约 6.4 m（两层外观）。

### 4.2 中央斜置篷布货物

- W 块：中心 (−7, 1.35, −3.2)，尺寸 10×2.7×3.2，yaw +32°。
- E 块：中心 (+7, 1.35, +3.2)，同尺寸同角度。
- 两块平行，形成**对角通道**（宽约 2.2 m，走向东北—西南），四端开口分别朝向两半场与前述大开口；地面中线被两块货物截断（半遮挡长视线，见 §5 SL1）。
- 弹道材质：篷布（tarp）可穿透、伤害衰减小于木箱（软质货物，含木质底座整体按软目标处理，已记录为玩法设定而非资料结论）。

### 4.3 木箱组（可穿透，跳跃链组成）

缓冲区：蓝 (44,−2.4)×2 层、(44,2.6)×1；红 (−44,2.4)×2、(−44,−2.6)×1。
中场：±18/±21/±28/±33/±36 处单-三层箱组（详见 mapData `CRATES`）。
斜货端部：(2.2,−6.6)、(−2.2,6.6) 单箱。
舷侧通道中段：(0,±13.2) 单箱（通道内唯一低位掩体）。
**右舷跳箱链**：单箱 1.1 m → 双箱 2.2 m → 箱顶 2.6 m（S4/S7 两处），普通双层堆（5.2 m）不可达。

### 4.4 端部舱室与出生

- 舱体 12×14×6.4 m；前墙正门宽 2.8 m 高 3.0 m，双侧门宽 1.6 m 高 2.7 m（z=±4.8）。
- 出生点各 5 个（舱内错列），朝向对方（沿 ∓X）。
- 舱侧（|x|>52, |z|>7.6）由机舱围蔽封死，防止绕出船体；舱顶不可达（装饰）。

### 4.5 边界与围护

- 舷墙：0.66 m 实体钢（挡人挡弹）；其上栏杆网面**不挡弹**，立柱（间隔 3 m）为实体挡弹——网孔/实体区分可解释。
- 栏杆安全墙（1.16 m 高，挡人不挡弹）防止跳出船舷；落海不可达，无需处理水下。
- **无地下通道**：经典端游运输船没有甲板下横贯通道（侧翼绕行为主）。任务提示的「地下道」说法在所选版本资料中无证据支持，故不纳入；若以 CFHD/其他版本为准需另核。**此为本重建最重要的版本判断之一。**

## 6. 资料缺口与近似（诚实记录）

1. **未取得同版本连续走图视频**：任务建议核验的"出生舱出口→侧道入口→高台返回甲板"连续连接，改为俯视图坐标推算 + 导航图全连通性测试（`tests/match.test.ts`）+ 实机走查（见 ACCEPTANCE A08）三重验证。行走体验中的细微高差以箱组可跳跃性为准。
2. **尺寸为估计值**：俯视图分辨率 553×415，甲板长度按人高比例推算，误差约 ±10%；未声称任何官方米制数据。
3. **箱体颜色分布**为艺术近似（参考图中蓝/锈红/绿均出现，具体段落归属按明暗分布估计）。
4. **吊机位置**（船首左舷）参照 R10 环境氛围图设置，非俯视图可辨目标；仅作环境装饰，基座有碰撞。
5. 手游/HD 版本差异（如部分版本的箱顶连跳、舱顶可达）未纳入。
