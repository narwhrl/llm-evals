# 验收记录（A01–A32）

执行日期：2026-09-28。执行环境：Windows 11（i7/GTX 级笔记本，具体型号未读取）、Chrome 内核内置浏览器（ZCode IAB，1440×900 视口、渲染像素比 1）、Node v24.21.0、npm 11.19.0。

标记说明：**通过**（有证据）/ **失败** / **未验证**（环境限制，附替代证据）。证据路径相对 `evidence/`。

自动化环境限制（适用于全部浏览器项）：IAB 自动化中 `cua` 坐标点击会物理移动光标，在指针锁定下产生额外视角甩动；因此射击/视角类操作使用**页面派生的真实输入事件**（mousedown/mouseup/keydown/mousemove，与用户输入同路径），移动/瞄准/开火均为游戏真实管线；未使用任何直接修改游戏状态的捷径（开发接口仅提供状态读取与固定机位/靶机）。
