# 运输船地图参照与重建记录

## 1. 版本选择

目标版本是**端游经典运输船**（团队竞技）。核心布局只采用 R04 页面中的 R05–R09 截图。这组截图来自同一篇 2018 年的图文攻略，画面风格、箱体配色和 HUD 一致，可以视为同一版本。

R10（新浪 2014 年 CF2.0 资料）的画质与构件不同，只用来观察吊机、海天和直升机等环境氛围，不参与布局。手游、CFHD 和第三方复刻均未使用。

同版本的连续走图视频**没有取得**。本次运行没有做视频检索，也没有记录任何视频时间戳。因此，出生舱内部、侧门与舷侧通道的精确连接，都是根据静态截图做的近似重建。

## 3. 坐标系与尺度（均为估计值，非官方数据）

- 单位为米。+X 指向东端（蓝方「保卫者」船舱），−X 指向西端（红方「潜伏者」船舱），+Z 为北舷，+Y 向上。
- 甲板面 y = 0。两端船舱平台 y = 1.2。
- 可游玩甲板长 100 m（x ∈ [−50, 50]），宽 25 m（z ∈ [−12.5, 12.5]），舷墙高 1.1 m。
- 比例通过以下方式校准：人物身高 1.8 m、视点 1.62 m；集装箱按标准 20 英尺箱取 6.06 × 2.44 × 2.6 m；木箱大箱 1.8 m、小箱 0.9 m；门高 2.3 m。这些数值和 R06、R07 中人物与箱体、门框的相对比例相符。
- 布局对地图中心做 180° 点对称：一侧的构件经 (x, z) → (−x, −z) 生成另一侧。这与 R05 的对位关系一致，两端的差异体现在朝向上（例如斜货物相对两个出生点的开口方向不同）。

## 5. 路线与连接

1. **主路（甲板中线）**：出生舱中门 → 三级台阶 → 出口木箱 → 中场阶梯箱组 → 斜置篷布货物 → 对方半场，与之呈点对称。电脑路线 `main`。
2. **北侧翼 / 南侧翼（舷侧通道）**：船舱侧门 → 下行台阶 → 集装箱排与舷墙之间约 3 m 宽的通道 → 对方船舱侧门。电脑路线 `flankN`、`flankS`。通道中段有小木箱和系缆桩作掩体。
3. **高点**：甲板 → `climb-s` 小箱（需跳）→ `climb-l` 大箱（跳蹲）→ `row0` 单层集装箱顶（y 2.6）。可以俯瞰本方出口与中场，但对方船舱被中场的双层箱遮住。电脑路线 `support`（偏向狙击枪），跳跃连接只存在于这条已验证的链上。
4. **流动**：`rover` 角色在热点之间随机选取目标。
5. **甲板下通道：没有纳入。** 所选版本的 R05–R09 中没有看到明确的地下入口、出口或楼层关系，所以只保留已确认的舷侧通路（任务 §2.2）。

双层集装箱顶不在寻路图中，也无法通过跳跃到达。寻路节点的最近点查询按楼层区分，不会把平台边缘下方的甲板点吸附到平台上（`tests/nav.test.ts`）。

## 6. 关键视线

- **中线长视线**：从红方中门台阶可以沿甲板中线看到对方出口木箱附近；被斜置货物和中场箱组分段切断，需要横移才能对枪。
- **舷侧通道**：直线纵深长，中段小木箱提供停顿点；集装箱排把通道和中线隔开。
- **斜货物转角**：货物与北舷约成 25°，在两端形成一宽一窄的开口，是近距离转角对枪的位置。
- **高点**：看得到本方半场的甲板，看不到对方舱内。舱内隔墙使得从门外无法直视后排出生位。

## 8. 近似与缺口

- 船舱内部（隔墙、储物柜、长凳、侧门位置）没有同版本的舱内截图，属于近似重建。
- 所有米制尺寸都是估计值。
- 缺少连续走图视频，路线连接只基于静态截图推断。
- 两端通过点对称生成。如果原版两端存在非对称的细节差异（例如某个箱子的具体位置），本重建不会体现。
- 吊机、直升机、海鸟、云层都是背景装饰，不可到达，也不参与战斗。
