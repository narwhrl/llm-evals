# 验收矩阵 A01–A32

执行日期：2026-09-30。浏览器为 Chrome 153（Windows 10.0.26200，Intel Arc 140T），视口 1440×900，DPR 1，画质中。

「方式」一栏中：
- **浏览器**：通过 Kimi WebBridge 用 CDP 发送可信输入（`Input.dispatch*`），能取得原生指针锁定。
- **调试**：借助 `?debug` 的 `window.__cf` 完成传送、固定机位、静止靶、冻结电脑和读取状态，伤害与计分仍走正式逻辑。
- **逻辑**：Vitest 测试。

本轮**没有人工手动实玩**。截图位于 `evidence/screens/`，测量日志位于 `evidence/*.json`。
