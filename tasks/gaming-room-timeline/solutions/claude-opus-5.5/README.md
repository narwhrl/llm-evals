# 二十年的游戏房

同一个房间的 2005–2025：一个玩家从十三岁卧室里的电脑角落，到三十三岁时完整的游戏房。用 Three.js 实时渲染；几何体全部由代码生成，贴图全部由 canvas 绘制。

## 安装、启动、构建

```bash
npm install
npm run dev        # 开发服务器，地址见终端输出（默认 http://localhost:5173/）
npm run build      # 生产构建，输出 dist/
npm run preview    # 本地预览 dist/（默认 http://localhost:4173/）
```

部署到子路径时直接使用 Vite 的参数，不需要额外配置：

```bash
npm run build -- --base=/gaming-room-timeline/claude-opus-5.5/ --outDir=<输出目录>
```

在 Windows 的 Git Bash 里，MSYS 会把 `--base=/...` 改写成 `/Program Files/Git/...`。请改用 PowerShell 或 cmd，或者在命令前加 `MSYS_NO_PATHCONV=1`。

页面在加载遮罩淡出后即可交互，此时第一帧已经渲染完成，`#loading` 元素会带上 `done` 类。

## 操作

**时间轴**

- 拖动底部滑块可以切换年份和月份。
- 点击 ▶ 或按空格开始自动播放，经过关键年份时会放慢。拖动滑块会停止自动播放。
- `←` / `→` 前后跳一年；数字键 `1`–`6` 跳到 2005 / 2008 / 2012 / 2016 / 2020 / 2025，也可以点击滑块下方的年份刻度。

**视角**

- 左键拖动旋转，滚轮缩放，右键平移。
- 右上角有四个视角按钮：全景、书桌、屏幕、角落。“角落”在 2020 年翻新前指向床尾堆放旧物的地方，翻新后指向复古角。
- 近距离查看时，挡在镜头前的椅子会自动隐藏。

**物品**

- 鼠标悬停会高亮物品并显示名称；点击会弹出卡片，内容是时代说明或主人的回忆。
- 卡片上的“靠近看看”会把镜头飞到物品旁边。按 `Esc` 或点击空白处关闭卡片。

**贯穿二十年的旧物**

- 右侧面板列出马克杯、绿萝、网吧合照、CRT、旧写字台、门边身高线、挂历和餐厅木椅。
- 点击某件旧物，镜头会飞到它当前的位置。
- 卡片里的年份标签会跳到那一年，镜头跟着物品走。

**电脑屏幕**

- 点击当前的主屏幕，镜头先飞到屏幕正前方；再次点击就是在操作电脑。左键点击；扫雷可以用右键插旗。
- 每个时代的桌面内容：
  - 2005 起，Windows XP 风格 + CRT：扫雷、QQ 好友列表、作业.txt、我的电脑，可以关机和重新开机。
  - 2008 起：对战平台大厅（加入房间 → 等待满员 → 载入地图）、千千静听、QQ 群聊天、扫雷。
  - 2012 起：游戏库（选择游戏、安装并显示下载进度、开始游戏）、千千静听、扫雷。
  - 2016 起：瞄准训练（15 个靶子，统计命中、失误和平均反应时间）、游戏库。旁边的副屏显示直播。
  - 2020 起，居家办公：视频会议（点“下班!”会关掉工作窗口、打开语音）、Q2 排期表、语音、游戏库。竖屏显示聊天，笔记本显示表格。
  - 2025：照片相册（每个时代一张，点“回到 XXXX”会跳到那一年的屏幕）、游戏库、语音、扫雷。
- 2020 年以后，旧 CRT 搬到复古角，循环播放像素赛车。这块屏幕和其他副屏都只显示内容，不能操作。

## 网络资源

运行时不加载任何网络资源：

- three.js 打包进构建产物；
- 字体使用系统字体（微软雅黑 / 苹方 / Noto Sans SC，Georgia）；
- 贴图全部由 canvas 实时生成，favicon 是内联 SVG；
- 没有后端，也不需要任何凭据。

只有 `npm install` 需要访问 npm registry。

## 代码结构

- `src/main.js`：渲染器、灯光、视角、时间轴、拾取、卡片和帧循环
- `src/timeline.js`：时代划分、物品出现/消失和移动的插值
- `src/room.js`：房间外壳，以及窗外天际线、挂历、身高线等随年份重绘的贴图
- `src/items.js`：全部物品，包括出现的年份、移动轨迹、说明和回忆
- `src/builders.js`、`src/kit.js`：各时代的显示器、主机、外设、椅子等构件，以及几何和材质工具
- `src/textures.js`：canvas 贴图，包括木纹、地板、布料、海报、挂历、身高线和天际线
- `src/screen.js`、`src/apps.js`：各时代的桌面系统和可操作的小程序
