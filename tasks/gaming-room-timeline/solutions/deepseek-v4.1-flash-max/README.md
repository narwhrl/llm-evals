# 二十年的房间 · 2005—2025

一个可以沿时间探索的微缩三维卧室。房间的基本格局不变，设备、家具、收藏、光线和生活痕迹随五个代表年份更替；豆豆猫玩偶、掉漆搪瓷杯、手绘太空猫和《星港：远征》初版盒贯穿二十年。

## 安装与运行

需要 Node.js 20+、npm 和 WebGL2 浏览器。已在 Node.js 24.21.0 / npm 11.19.0、Chrome 1440 × 900 下验证。

```bash
npm install
npm run dev
```

打开终端里 Vite 打印的本地地址。

生产构建接受 Vite 的 `--base` 和 `--outDir`：

```bash
npm run build -- --base=/gaming-room-timeline/deepseek-v4.1-flash-max/ --outDir=dist --emptyOutDir
```

构建后可在对应子路径下静态托管 `dist/`，或使用：

```bash
npm run preview
```

## 操作

- 拖动：环绕房间；滚轮：缩放；`全景` / `桌面`：切换观察距离。
- 时间轴：拖动 2005—2025 的滑杆，或点击年份刻度；`自动播放` 连续走完全程，拖动滑杆会暂停。
- 点击床、书桌、键盘、主机、椅子、豆豆、搪瓷杯、手绘、旧 CRT、吉他、窗、台灯、床尾柜、角落座椅等，会打开当年代记忆卡。
- 点击显示器进入对应年份的电脑界面；先 `启动游戏`，再移动鼠标并点击漂来的星舰/碎片。`Esc` 离开屏幕。
- 键盘：`Space` 播放/暂停，`←` / `→` 调整年份，`1` / `2` 切换视角，`Esc` 关闭记忆卡或屏幕。

## 资源说明

不依赖任何外部网络资源、CDN、字体服务、图片或音频。墙面、木纹、布料、海报、窗外街景、屏幕 UI 和游戏画面都由 Canvas 在运行时生成。没有后端、账号或持久化存储。

## 结构

```text
src/
  main.js      # 渲染循环、灯光、相机、输入与 HUD 连接
  world.js     # 房间、五个年代、家具、收藏和可点击区域
  content.js   # 年份叙事、记忆文本、屏幕界面配置
  screens.js   # 3D 屏幕绘制、屏幕叠层和可玩的小游戏
  textures.js  # 程序化纹理
  style.css    # HUD、记忆卡与页面
  screen.css   # 五个年代的桌面/游戏界面样式
```
