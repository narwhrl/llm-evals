# 一间房，二十年 · Gaming Room Timeline

一个在浏览器里实时渲染、可自由观察的微缩房间。同一间卧室从 2005 年的电脑角，慢慢长成 2025 年的电竞房：设备、家具、收藏、墙上的东西和留在角落的旧物都在换，桌子的位置、窗、门和那只杯子、那只恐龙、那张拍立得没有换过。

## 安装、启动与构建

需要 Node.js 20+（在 Node 24 / npm 11 上验证）。

```bash
npm install          # 安装 three 与 vite
npm run dev          # 开发服务器：http://localhost:5173
npm run check        # 静态语法检查（src/*.js 与配置）
npm run build        # 生产构建，输出到 dist/
npm run preview      # 预览生产构建：http://localhost:4173
```

构建产物是纯静态文件，可以用任意静态服务器托管 `dist/`，不需要后端、账号或环境变量。

## 网络资源

**没有运行时网络资源。** 木纹、墙纸、布艺、地毯、海报、拍立得、光盘盒书脊、屏幕里的桌面和游戏画面，全部由 Canvas 2D 在浏览器里程序绘制；几何体由代码生成。不请求 CDN、外部图片、字体、模型文件或任何 API，离线打开构建产物也能完整运行。

`npm install` 阶段需要安装 `three` 和 `vite` 两个 npm 包（或命中本地 npm 缓存）；这是构建依赖，不是运行时依赖。

浏览器需要支持 WebGL2 与 ES modules 的现代桌面浏览器。评审视口为 1440 × 900。

## 操作

- **年份滑杆**：拖动 2005—2025，设备与摆设会在年份之间交叉淡入淡出；六个刻度是代表年份（2005 / 2009 / 2013 / 2017 / 2021 / 2025）。
- **自动播放**：点击「自动播放」或按空格，速度按钮可在 1× / 2× / 4× 之间切换；播放中随时拖动滑杆即接管为手动。方向键每次挪一年。
- **看房间**：鼠标拖动旋转、滚轮缩放；右上角「全景 / 桌面 / 旧物角」切换预设视角，靠近桌面时会出现屏幕提示。
- **读记忆**：点击带说明的物品（显示器、主机、键盘、手柄、桌椅、床、沙发、柜子、海报、旧物……）会浮出当年的说明或主人的一句话。左下角列出三件贯穿二十年的旧物，点名字会把镜头带过去并显示那一年的记忆。
- **屏幕可操作**：显示器是一张实时绘制的 Canvas 贴图，点图标、按钮、格子会打开窗口或玩两下，窗口右上角 `×` 回到桌面。每个年代内容不同：2005 是 XP 式桌面、扫雷和 CS；2009 是游戏库 / 赛车 / 下载；2013 是联赛客户端与技能；2017 是游戏库与详情；2021 是直播台；2025 的「2005」文件夹里还能再打开 2005 年那一关。

## 六个年代与旧物线索

| 年份 | 房间里发生的事 |
| --- | --- |
| 2005 | 小书桌、CRT、米白机箱、CD 盒、单人床、挂历；拥挤朴素 |
| 2009 | 宽屏 LCD、黑机箱、主机手柄、木书架；床还在 |
| 2013 | 双屏、侧透机箱、机械键盘、金属架、赛程表；床换成了沙发 |
| 2017 | 大屏、洞洞板、玻璃展示柜、奖杯、吸音板；房间不再像卧室 |
| 2021 | 显示器臂与竖屏、麦克风、补光灯、声学板、直播 |
| 2025 | 更宽的屏与升降桌；旧物角留着盖布的 CRT、旧键盘和光盘 |

三件**贯穿二十年**的旧物：桌右的褪色马克杯、窗台的绿色小恐龙、背墙上的拍立得合影。点击它们时，说明会随当前年份换成那一年的记忆。另有几件「没扔」的东西：2005 的一对小音箱（2013 年后挪到窗台继续用）、夹式台灯（2017 年后收进旧物角）、CRT 显示器（2010—2013 年从桌面搬进墙角并盖上布）、光盘盒与旧手柄。房间布局、窗、门、纸箱和暖色主光始终不变，年代变化由物件承担。

## 项目结构

```
index.html          UI 骨架
src/style.css       界面样式
src/main.js         渲染器、相机、时间线、点击与 UI 绑定
src/eras.js         代表年份与年代段
src/room.js         房间结构、窗、门、灯光
src/kit.js          几何 / 材质工具、时间线标记
src/textures.js     程序纹理
src/materials.js    共享材质库
src/desk.js         六代桌子、显示器、主机、外设
src/furniture.js    椅子、床 / 沙发 / 柜、收藏架
src/decor.js        墙饰、三件旧物、旧物角
src/screens.js      屏幕内容绘制与点击交互
src/timeline.js     年份权重与旧物搬迁插值
src/props.js        组装与时间线配置
scripts/check.mjs   静态语法检查
```
