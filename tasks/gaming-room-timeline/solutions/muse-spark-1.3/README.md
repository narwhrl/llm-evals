# 一间房 · 二十年 — gaming room timeline

同一个房间，2005 → 2025：从卧室电脑角长成电竞房。
程序化三维微缩场景（Three.js），零外部资源，离线可运行。

## 安装 / 启动 / 构建

```sh
npm install
npm run dev      # 本地开发：http://localhost:5173
npm run build    # 生产构建 → dist/
npm run preview  # 预览生产构建：http://localhost:4173
```

Node ≥ 18。网络资源：无——场景、贴图、屏幕界面全部由代码程序化生成，
`npm install` 之后运行与构建不再需要网络。

## 操作

- 时间滑杆（2005—2025）：拖动跳转，刻度可点；▶ 自动播放约 15 秒走完二十年，随时拖动可接管。
- 视角：拖拽旋转、滚轮推近；右上「全景 / 桌面特写」一键飞到机位。
- 点击物品：约 15 类可点（电脑屏幕、主机、闹钟、玩偶、手柄、第一张海报、书架、
  纸箱、椅子、游戏机、麦克风、床、CRT、吸音板、绿植……），弹出年代说明 / 主人记忆。
- 点击电脑屏幕：在年代桌面 ↔ 可玩小游戏之间切换；游戏中 ← → / 鼠标移动挡板，空格发射。
- 情感线：蓝色小闹钟、旧玩偶、第一个手柄、第一张海报贯穿二十年，
  注意它们从桌上搬到书架、挂上墙的位置变化。

## 技术

- `src/main.js` — 场景、年代插值（fader + mover）、交互、UI。
- `src/screen.js` — 六个年代的桌面 / 游戏大厅 Canvas 界面 + 打砖块小游戏。
- 代表年份：2005 / 2009 / 2013 / 2017 / 2021 / 2025；年份之间相邻装备组交叉淡入淡出，
  旧物（CRT、纸箱、手柄）退居角落或上墙，灯光色温随年代微调。
