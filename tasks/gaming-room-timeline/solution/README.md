# 二十年，一间房（2005—2025）

同一个房间里一位玩家二十年的游戏时光：从卧室靠墙的小电脑桌，到完整的电竞房。Three.js 实时渲染的微缩场景，全部模型、贴图和屏幕内容都由代码生成。

## 安装、启动、构建

需要 Node.js 20.19+（开发时使用 24.21）。

```bash
npm install        # 或 npm ci
npm run dev        # 开发服务器，默认 http://localhost:5173/
npm run build      # 生产构建到 dist/，接受 Vite 的 --base 与 --outDir
npm run preview    # 本地预览 dist/，默认 http://localhost:4173/
npm test           # 故事时间表与扫雷规则的自检（node --test）
```

部署到子路径时：`npm run build -- --base=/<task-id>/<candidate-id>/ --outDir=<目录> --emptyOutDir`。

## 网络资源

运行时不依赖任何网络资源：没有 CDN、远程字体、图片或后端，字体使用系统字体。只有安装阶段需要从 npm 下载 `three` 和 `vite`。

## 操作

| 操作 | 方式 |
| --- | --- |
| 旋转 / 缩放 / 平移 | 左键拖动 / 滚轮 / 右键拖动；绕到墙外时，挡住视线的墙会自动隐藏 |
| 视角 | 右上角「全景」「桌面」「屏幕」 |
| 时间 | 拖动底部滑杆（2005—2025），或点刻度上的年份；▶ 自动播放，播放中仍可直接拖动滑杆 |
| 物品回忆 | 指针移到物品上会显示名字，点击弹出年代说明或主人记忆；同一件物品在不同年份说的话不同 |
| 旧物线索 | 右上角「贯穿二十年的旧物」逐个定位：第一台电脑、台灯、小恐龙、搪瓷杯、仙人球、格子被、第一盒游戏、海报 |
| 操作电脑屏幕 | 直接点击场景里正在使用的显示器；「屏幕」视角看得最清楚 |

各年代屏幕上能点的东西：

- 2005：扫雷、音乐盒、开始菜单（可以关机再开机）、《剑与远方》快捷方式
- 2009：团队副本放技能打首领、公会群发消息
- 2013：游戏库选游戏、开始/停止、接受好友邀请
- 2017：大逃杀大厅切换模式、邀请队友、开始匹配并等对局结束
- 2021：会议静音 / 开摄像头 / 离开，小岛上抛竿、等咬钩、提竿
- 2025：模拟器里继续 2005 年那一局扫雷（同一个棋盘）、翻回忆相册、回复消息

## 结构

- `src/story.js`：故事数据表——每件物品的出现与离开年份、位置（含搬动的关键帧）、回忆文字、章节文案。
- `src/timeline.js`：把数据表变成场景物体，按年份做出现 / 离开 / 搬动的过渡。
- `src/room.js`：房间外壳、窗、门、灯光；2016 年的重新装修是墙面和地板颜色的渐变。
- `src/furniture.js` `tech.js` `gear.js` `keepsakes.js` `clutter.js` `collection.js`：各类物体的建模函数。
- `src/screens.js` + `src/app-*.js`：画在 canvas 上的各年代桌面；点击通过射线命中的 UV 映射到界面。
- `src/main.js`：渲染、相机、拾取和界面。
