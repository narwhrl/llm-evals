# Gaming Room Timeline

一个离线可运行的 Three.js 微缩房间。拖动时间轴查看 2005—2025 年间同一房间从卧室电脑角逐步成长为电竞房的变化。

## 安装与运行

```bash
npm install
npm run dev -- --host 127.0.0.1
```

打开终端输出的本地地址（默认 `http://127.0.0.1:5173/`）。生产构建：

```bash
npm run build
npm run preview
```

运行时不请求外部图片、字体或 API；屏幕内容由本地 Canvas 纹理绘制。`npm install` 需要访问 npm registry 下载 `three` 与 `vite`。

## 操作

- 拖动底部时间轴，或点击 `Play` 观看 2005—2025 的连续变化。
- 鼠标拖动旋转视角，滚轮靠近桌面；点击桌面、屏幕、灯、收纳箱、收藏架等物件打开年代说明和主人记忆。
- 点击显示器可轮换对应年代的简化桌面 / 游戏界面。
- 房间格局保持稳定；CRT、米色塔式机、现代玻璃机箱、海报和收藏会在合理年份替换，红色杯子、橙色台灯和记忆板贯穿整个时间线。
