# 轨道之家 · 空间站生活舱

一个正交等距视角的空间站生活舱微缩模型网页：纵向剖开的胶囊舱段、厚壁剖面、带真实开孔的大舷窗，以及窗外一颗会随 90 秒轨道周期昼夜交替的 3D 地球。页面上没有任何 UI 元素，全部内容由场景本身承载。

## 运行

```bash
npm ci                 # 依赖锁定在 package-lock.json
npm run dev            # 开发服务器
npm run build          # 生产构建（默认输出 dist/）
npm run preview        # 预览生产构建
```

生产构建接受 `--base` 与 `--outDir`：

```bash
npm run build -- --base=/some/prefix/ --outDir=out
```

Git Bash 下如果 `--base=/...` 被转换成 Windows 路径，加上 `MSYS_NO_PATHCONV=1`：

```bash
MSYS_NO_PATHCONV=1 npm run build -- "--base=/some/prefix/" "--outDir=out"
```

## 操作

| 操作 | 效果 |
| --- | --- |
| 拖拽空白处 | 旋转视角（方位角 22°–68°，俯仰角 20°–55°，限制在能看清舱内的范围） |
| 滚轮 | 缩放 |
| 点击工作台 / 睡袋 / 种植架 / 观景座椅 / 健身车 / 储物区 | 平滑聚焦到该区域，再点一次或点空白处返回全景 |
| 在大舷窗内按住并左右拖动 | 手动拖动轨道时间，松手后从该时刻继续自动流转 |
| 单击大舷窗（不拖动） | 昼夜循环加速到 15 秒一圈，再次单击恢复 90 秒 |
| 点击漂浮笔 | 笔快速旋转 |
| 鼠标靠近漂浮笔 | 笔被气流扰动般躲开 |
| 点击植物生长灯 | 关闭 / 开启绿植角照明 |
| 点击地板灯带 | 切换夜航模式：主灯带熄灭，只剩阅读灯、屏幕光、指示灯和地球光 |

单击与拖动的区分阈值是 7 px 位移，因此舷窗上的「拖时间」和「快进」不会互相误触。

## 结构

```
src/
  main.js         渲染器、正交相机、昼夜/光照状态机、交互与动画循环
  layout.js       舱段尺寸、舷窗位置、取景参数、舷窗遮挡判定
  hull.js         舱壁（带真实开孔的 ExtrudeGeometry）、肩部壳体、加强筋、地板、端舱壁
  furnishings.js  睡眠、工作、观景、绿植、健身、储物六个区域与漂浮物
  details.js      舱壁/舱顶/地面的二级细节层（面板、标签、管线、网兜、杂物）
  earth.js        地球着色器（昼夜混合、云层、大气辉光）、舷窗 stencil 遮罩
  materials.js    材质与贴图装配
  textures.js     程序化贴图（舱壁、格栅、织物、标签、照片、屏幕、叶片等）
  utils.js        几何与实例化工具
  assets/         NASA 公有领域地球贴图
evidence/         1440×900 实机截图
```

### 舷窗遮挡判定

等距投影下，贴着舱壁放在舷窗「旁边」的物件仍可能投影到玻璃上。`layout.js` 里的 `wallClear()` / `pathClear()` 把每扇舷窗投影成屏幕空间的椭圆，并对首屏取景与全部聚焦取景逐一测试；`hull.js`、`details.js`、`furnishings.js` 里所有壁挂件都先过这道判定再落位，因此舷窗在任何可达视角下都只显示地球。

### 地球

每个舷窗各有一颗真实的 3D 球体（等距柱状投影贴图 + 云层），用 stencil 限定为只在窗口开口内可见。球体半径大于窗口开口，因此窗口内看到的是球面的一部分，边缘会露出地平弧线与大气辉光。昼面用白天贴图、夜面切到城市灯光贴图，二者在同一着色器里按太阳方向混合。地球在正交相机下按屏幕空间锚定在舷窗后方，所以旋转舱段时窗口内的地球不会漂移。

## 已知限制

- 地球贴图是 2048×1024 的等距柱状投影，极点处有正常的拉伸；由于舷窗只显示球面的一部分，极点不在视野内。
- 白天地球的云层与陆地亮度经过调校以匹配舱内曝光，并非物理正确的辐照度。
- 场景按桌面 1440×900 视口调校；更窄的窗口下正交视锥会按宽高比调整，但构图不如基准视口紧凑。
- 动画全部基于 `requestAnimationFrame` 的真实时间推进，后台标签页暂停时昼夜循环也会暂停。
