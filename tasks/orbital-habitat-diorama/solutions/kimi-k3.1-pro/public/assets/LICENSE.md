# Local asset provenance

## Earth maps

- `earth-day.jpg`: Solar System Scope, `2k_earth_daymap.jpg`.
- `earth-night.jpg`: Solar System Scope, `2k_earth_nightmap.jpg`.
- `earth-clouds.jpg`: Solar System Scope, `2k_earth_clouds.jpg`.

Source: https://www.solarsystemscope.com/textures/

The three unmodified source images were downloaded on 2026-10-26 and are distributed under Creative Commons Attribution 4.0 International (CC BY 4.0).

License: https://creativecommons.org/licenses/by/4.0/

Attribution: Earth day, night and cloud textures by Solar System Scope (https://www.solarsystemscope.com).

The source page states that these textures may be used, adapted and shared for any purpose, including commercially. The runtime blends the maps in a custom Three.js shader; the source image files themselves are not altered.

## Generated assets

All other visual assets are generated by the included project code:

- `src/materials.js`: painted metal, seams, rivets, scratches, floor grating, fabric weave, worktop grain, orbital telemetry, paper, technical diagrams, family-photo illustrations, handwritten note and equipment labels.
- `src/habitat.js`, `src/furniture.js`: all cabin and furnishing geometry.
- `src/environment.js`: Earth atmosphere, window composition, moving sunlight patch and lighting.

No third-party models, icon packs, stock photos, fonts or remote runtime resources are used. Generated family photos are geometric illustrations, not photographs of real people.
