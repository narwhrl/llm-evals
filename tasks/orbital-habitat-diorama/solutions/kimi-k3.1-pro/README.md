# 轨道之家 · Orbital Home

一个没有可见 UI 的正交等距空间站生活舱。所有几何、文字纹理和地球素材均在本地；运行时不请求远程图片、字体或服务。

## 安装与启动

需要 Node.js 22.12 或更高版本（开发验收使用 Node.js 24.21.0）。

```sh
npm ci
npm run dev -- --port 4174
```

打开终端显示的本地地址。

## 操作

- 拖动舱体空白区域旋转，滚轮或双指缩放；镜头保持正交投影并限制旋转范围。
- 点击睡袋、种植架、工作台、观景座椅、健身车聚焦；再点同一物件或空白处返回。
- 在大舷窗按住地球左右拖动，手动调整轨道时间；松手后继续自动流转。
- 单击大舷窗在 90 秒和 15 秒昼夜周期之间切换。
- 鼠标靠近漂浮笔时笔会避让；点击笔会加速旋转。
- 点击种植架顶部粉紫灯关闭或打开植物生长灯。
- 点击地板暖白灯带切换夜航模式；阅读灯、植物灯、屏幕与设备灯保留。

## 生产构建与预览

```sh
npm run build
npm run preview -- --port 4175
```

Vite 的 `--base` 和 `--outDir` 参数可直接追加，例如：

```sh
npm run build -- --base=/orbital-habitat-diorama/kimi-k3.1-pro/ --outDir=dist --emptyOutDir
```

预览非根路径时，需要在本地静态服务器把该目录挂载到相同 URL 前缀；构建生成的 JS、CSS 和 `public/assets/` 图片均以此前缀引用。

## 实现

- Vite 7 + Three.js，无服务端或凭据依赖。
- 后壁为连续曲面挤出壳体，按窗筒法向的投影裁出三个真实开口。窗框、地球视窗和开口共用位置与角度；独立窗筒、内外密封和压环贴合曲面。端部八角框依附端盖，顶部薄环只表示剖切壳体与夹层断面。
- 地球为共享的 Three.js 球体，具有 2:1 日面、夜面、云层和大气着色器。三个舷窗各自以透视相机实时渲染同一球体，主舱体使用正交相机。
- 90 秒轨道周期由实际经过时间驱动。浏览器可能节流后台标签页；交互与计时验收在可见的活动标签页进行。
- 静态共享材质几何在初始化时合批；动态物体、灯光和屏幕单独保留。
- `evidence/` 保存实际运行在 1440 × 900 视口下的五张截图；没有截图专用模型、图片覆盖或后期合成。
- `window.__habitat` 是只读验收诊断接口，可查看当前交互状态和屏幕投影坐标，不提供改变场景状态的函数。
