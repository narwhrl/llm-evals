# 轨道之家 · 空间站生活舱

An isometric cut-away of an orbital habitat module, rendered in the browser.
A capsule section is opened along its length, the cabin inside is furnished
for one person who has lived there for half a year, and a planet hangs outside
the big porthole. The module orbits: the sun swings around it once every
ninety seconds, the light comes in through the window and lays a round patch
on the floor, and when the module passes into the Earth's shadow the window
fills with the night side of the planet.

Everything is drawn with Three.js. There is no interface on the page: the
module is turned by dragging it, clicked to look at something, and the
porthole is dragged to move the orbit.

## Requirements

- Node.js 20 or newer (developed on 24.21.0)
- npm 10 or newer (developed on 11.19.0)

No backend, no accounts, no keys, no network access at runtime.

## Install

```bash
npm ci          # exact versions from package-lock.json
npm install     # same, if the lock file is not wanted
```

## Develop

```bash
npm run dev         # http://127.0.0.1:5184/
npm run typecheck   # tsc --noEmit
npm run assets      # regenerate public/assets/*.png (see below)
```

## Build and preview

```bash
npm run build                                  # type check + production build into dist/
npx vite build --base=/gallery/orbital/ --outDir=dist-sub   # non-root base, custom output folder
npm run preview                                 # serves dist/ on http://127.0.0.1:4184/
```

The build takes `--base` and `--outDir`. The default base is relative (`./`),
so the same bundle works from a domain root and from any subdirectory; the
textures are requested with relative URLs and are shipped in the build, so
they resolve the same way.

Any static file server works as well:

```bash
npx serve dist
python -m http.server 8080 --directory dist
```

## The scene

| File | What it holds |
| --- | --- |
| `src/scene/capsule.ts` | The hull: the cut shell, the portholes, the floor, the end bulkheads, the ring stiffeners. |
| `src/scene/props.ts` | Everything in the cabin: the sleeping bay, the work station, the plant rack, the seat, the exercise corner, the clutter. |
| `src/scene/earth.ts` | The planet outside the window: a 3D sphere with day, night and cloud maps. |
| `src/scene/habitat.ts` | The diorama itself: the orthographic camera, the orbit, the light, and every interaction. |
| `src/scene/textures.ts` | Loading of the local textures and the palette. |
| `src/App.tsx` | The page, and the `window.__HABITAT__` interface used by the acceptance harness. |
| `tools/generate-assets.mjs` | The generator that writes every texture in `public/assets/`. |

## Controls

| Gesture | What it does |
| --- | --- |
| Drag the module | Turns the diorama. The rotation is limited to the angles where the cabin stays visible. |
| Wheel | Zooms. |
| Click the work station, the sleeping bay, the plant rack, the seat, the exercise bike | The camera eases in on it. |
| Click the same thing again, or click the floor | The camera eases back to the overview. |
| Drag the Earth in the big porthole | Scrubs the orbit. Releasing continues from that moment. |
| Click the big porthole | The orbit speeds up to fifteen seconds a turn. Click again to go back to ninety. |
| Move the pointer near the floating pen | The pen drifts away from the cursor. Click it and it spins. |
| Click the grow lamp | Switches the pink grow light off and on. |
| Click the light strip in the floor | Night cruise: the main lighting goes out and the module sinks into blue black. |

## The automation interface

`window.__HABITAT__` exposes `state`, `getState()`, `setPhase()`, `setFocus()`,
`setFastForward()`, `setNightCruise()`, `setPlantLight()`, `project()` and
`landmarks()`. It is used by the acceptance harness to drive the page and to
find the screen position of the things that can be clicked.

## Assets

Every texture is generated by `tools/generate-assets.mjs` with no input from
outside the project, and is written to `public/assets/`:

- `earth_day.png`, `earth_night.png`, `earth_clouds.png` — 1024 × 512 equirectangular maps sampled from 3D value noise on the sphere, so the left and right edges meet and the poles do not smear.
- `wall_panels.png` — the enamel plate wall with its seams, rivets and stencilled labels.
- `floor_grate.png` — the anti-slip grating.
- `fabric_bag.png`, `fabric_towel.png`, `desk_top.png`, `memo_board.png`, `book_pages.png`, `net.png`, `leaf.png`, `blueprint.png`, `cable_wrap.png` — the surfaces of the things in the cabin.

Run `npm run assets` to rebuild them. The generator is deterministic: the same
file always produces the same pixels.
